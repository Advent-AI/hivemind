**Step one should not be sent yet.** The proposed test can pass without showing that the new period field is useful, and the reader packet can reveal which arm produced an answer. The design needs those counting and blinding issues fixed before the sends.

- **The period line can pass with every period empty.** It limits wrong fixed periods but only reports missing ones. Require an exercised set of figures whose articles establish a year or quarter, and a prewritten minimum for correctly populated periods. Keep unsupported relative periods as `null` controls. If either set is absent, the period line is unexercised.
- **The party line can reward disappearing figures.** It scores a named figure only when an arm keeps it; “neither arm keeps it” is the only explicit unexercised case. Thus c21 could keep a figure once, attribute it correctly, drop it twice, and pass that figure while pooled counts hide the loss. Compare retention of each named figure with c8, require enough retained sends to exercise attribution, and define zero-kept and low-control cases explicitly.
- **Counts do not guard correct filing.** The pooled kept-and-linked line can pass if a useful statement is dropped or linked to the wrong question while another is added. Blind readers need to compare the named facts and their destinations, including wrong links and unsupported new links, not only totals. Likewise, guard source passages, speaker, date and qualifications: the extra fields could change those even when measure, value and kind remain correct.
- **The three-send opening guard is too coarse to establish preservation.** A move from 2/3 to 1/3 on a case does not necessarily trigger the individual threshold, and pooling can conceal it. With the known c8 spread, report per-case differences and allow an inconclusive outcome; a non-failure should not be described as proof that openings were preserved. Define how valid-send shortages affect pooled denominators and make empty figure populations unexercised.
- **The packet is not demonstrably blind.** c21’s fixed periods must match `FY2027-Q3`-style syntax; c8’s substituted periods are free text, often “fiscal third quarter” or “last quarter.” A reader can infer the arm from formatting. Prepare a common display that preserves the underlying meaning and unknowns without exposing this signature, and check blindness on the actual packet before sending.
