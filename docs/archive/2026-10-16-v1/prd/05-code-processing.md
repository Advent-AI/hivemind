# 代码处理

## 一句话

股价、财务报表、CPI 这类整齐的表格数据，由程序直接读出数字，存进研究库。

## 已经确定的要求

- 只处理分发交来的表格类信息。
- 不用模型，不花钱；同样的输入，每次结果都一样。
- 读出来的每条事实都写明讲的是谁（公司、加密货币、商品或主题）。
- 每条信息处理完，在研究库里写一条处理记录。
- 不按日期跑：信息来了就处理。

## 例子

- 一条 CPI 数据 → “9 月美国 CPI 同比 3.2%”，挂在主题“美国通胀”上。
- 一条 XBRL 收入数据 → “Apple 第三财季收入 xxx 亿美元”，挂在 Apple 上。

## 还没定的

- 读出来的事实长什么样（和模型抽取共用一种结构）。
- 每个数据集的字段怎样对应成事实。
- 读失败了怎么办。

## 相关决定

- D7：写处理记录，不存原材料。
- D11：事实挂在对象上。
- D13：由信息推动。
