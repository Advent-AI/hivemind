## 4. B 的具体合同（代码前）

清单只列可参考的量和范围。所有候选仍走原有年份、出处、对象、梯子检查；清单外本身不再是拒绝理由。
清单外标记从原答的键与清单可重算，不增加一条人工审批流程。

单年转换只接受完整的 `YYYY`、`FYYYYY`、`FY YYYY`、`YYYY年`、`YYYY财年`（大小写不敏感）。
完整的 `YYYY自然年`、`CY YYYY` 按自然年。其余写法保留原始合法日期区间，不把首个数字当作财年。
日期必须是真实日期，起始不晚于结束。

范围只在与清单名称规范化后精确相同时使用清单写法；部分别名只说明可能相关。
原来的无范围指标只清掉确实重复表达量或口径的全文（空值、GAAP/non-GAAP、指标自身名称及二者组合）。
不得因为量是 operating_loss 就清掉 Reality Labs，或者因为量是 capex 就清掉 cash；有额外限定就保留，由模型比对。
这是同一个范围丢失机制：全量原答有 Reality Labs 1 条、cash CapEx 1 条，取消清单门槛后会走到这里。

共同的键比较函数供搜索后的身份检查与写入复用：对象、量、范围、起止日、口径、单位、事件类型。
自动认定重复要求各项完全一致，且范围由代码确定，量或事件类型不是含糊的 `other`；`n/a` 不可充当自动合并的通配符。
搜索可以召回口径未知的候选，交给模型判断；不能把“搜到了”当作“同一个”。
同批新建中键完全相同的候选只建一条，全部证据保留，依赖按最终编号检查；不同事件或时期不合并。
同批用输入顺序第一条的问题和梯子；合并后的依赖去重。若接续目标或同一依赖的方向冲突，整次拒绝，不能默默选择；解析后形成环也拒绝。
上述合并计划和冲突检查共用一个纯函数，在 matching.check 返回成功之前运行，问题进入现有拒绝重试，让模型有机会改正依赖；writer 事务内用同一函数复查，不能只在缓存回答之后无期限拒绝。
数据库已有同键而新写入仍请求新建，写入拒绝并回滚，让身份步骤重新决定，不绕过原有证据比对。
这里的“同键”仅指符合上述自动认定条件的键，不能阻挡两个尚需模型区分的自由范围。
新写入带代码产生的键合同版本 2；旧键、旧 handover 没有这个标记，不因旧 `scope_source=watch/none` 获得自动合并资格。它们仍作为语义比对候选，不能仅因旧的错误时期或范围被排除；不回填旧值。
数据库打开及写入边界共用函数补缺失列（版本、旧库缺失的 scope_source/rung bounds），覆盖已打开连接中恢复旧备份的路径；读取函数不改表，未带键的旧梯子保持原返回格式。
writer 在已有事务内设保存点，或先取得 SQLite 写锁再设保存点；成功由 round 连同完成标记一起提交。
异常回到保存点，round 写失败记录；此前已持久化的 handover/比对记录可用于恢复，不留半次观点写入。
replay 遇到失败结果立即停止，不能把失败的输入所在日期记成完成；否则新写入拒绝没有重试入口。恢复时由已有处理记录取回同一顺序号和 handover。

### 状态 × 事件

| 状态 | 事件 | 行为、写入与时间 |
|---|---|---|
| 未抽取 | 清单内或外原答 | 同一套源码检查；只读当前输入发布日和已展示信息，不读系统日期 |
| 未抽取 | 单财年 / 自然年 / 多年 | 分别转换 / 自然年 / 保留合法原区间；非法日期拒绝该候选 |
| 已抽取 | 第一次或修正后的比对回答 | 同一键比较；拒绝不合适目标；不因重试放宽 |
| 已比对 | 同批同键 / 不同键 | 一个新观点并保留全部编号映射 / 分别新建；用当前分发序号 |
| 写入中 | 既存同键、异常或崩溃 | 整次写入回滚；不记录完成；重送仍用原分发序号 |
| 已写入 | 相同输入重送 | 原分发跳过；不重复写入 |
| 恢复中 | 改配置或更正输入 | 已存 handover 不重新解释原答；更正输入用新编号，原输入不改写 |
| 不同输入 | 后一天、两家公司或两个写者 | 键包括对象与时期；已有同键检查在同一写入事务内；竞争写入失败后由原恢复流程重来 |

### 值 × 写者 × 读者

| 值 | 全部写者/输入来源 | 读者与约束 |
|---|---|---|
| 范围、时期 | 模型原答→sift；旧 handover 恢复；历史导入不改 | matching、writer、view_keys、service；新原答修正，旧记录只读原值，不暗中迁移 |
| 相同键 | 共同纯函数，输入候选或 view_keys | matching、writer；搜索放宽不改变身份等式 |
| 候选到观点映射 | writer 新建、同批复用；matching 已有目标 | 证据、依赖、统计；新建数量按唯一观点编号计 |
| 清单 | universe 配置 | 提示词、范围精确名称、搜索线索；不再用来丢弃候选 |
| 处理完成 | round 与 dispatch | replay 恢复、按日统计；仅与成功写入一起提交 |
