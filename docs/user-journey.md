# 用户旅程 v2：把看价格换成看赌注

讨论稿，2026-10-22，第二版。Claude 写，Alex 还没定。第一版（故事和未来畅想）留在 scratchpad，这一版从目标用户每天实际做什么开始，再推产品该长什么样。配 `docs/killer-experience.md`（方向）和 `docs/joyce-challenge.md`（挑战记录）。

## 一句话

有故事的散户一天打开行情很多次，几乎每次看的都是价格和红绿。他的交易是价格引起的情绪做的决定，thesis 是事后用来说服自己的。thesis 从来没写下来，所以查不了，所以会漂。**产品要做的不是多一个 app，是把他本来就在做的那个动作「看价格」换成「看赌注」：打开的时候先看到「你信的几件事有没有变」，价格退到第二行。** 这一个替换，改的是三个行为：红盘日的冲动、破了还拿着、从不复盘。

## 1. 目标用户是谁，不是谁

按行为分，散户有五种。只有一种是我们的。

| 谁 | 行为 | 是不是我们的 |
|---|---|---|
| 被动的人 | 定投指数，不看 | 不是。Wealthfront 的 |
| **有故事的持有者** | 拿 3–10 只有故事的东西：NVDA、TSLA、PLTR、ETH。天天看价，一季交易几次。有看法，没时间，没方法 | **是** |
| 短线和 meme | 按流量和情绪，一天几次，期权 | 不是。Joyce 说的「看到就买」 |
| 刷量和 farming | bot、网格、DCA | 不是，除非 bot 要一个理由（节拍 5） |
| 跟单的人 | 跟大 V、跟策略 | 一半：他跟的那个人的话可以变成一张注 |

有故事的持有者是 Alex 自己。他说过：「我很想参与，但没有一个 educated 的方式」；「赚钱的是不动、一直买的 NVDA，瞎操的都亏」。这群人占活跃散户的多少，没数；但他们是单只股票里钱最多、焦虑最多的一群。

## 2. 他今天一天、一季、一年在做什么

一天：
- 打开行情很多次。绝大多数打开不交易，只是看一眼红绿。看是主要行为，交易是副产品。
- 看完的情绪由两样决定：今天的涨跌、和他买入价比是赚是亏。和 thesis 无关。
- 跌了，第一反应是搜「为什么跌」。搜到的是头条和推特，分不清哪条和他拿的东西有关。
- 决定在几分钟内做，在手机上，没有计划。触发是价格提醒或一条头条。

一季：
- 财报那一周是情绪顶点。要么当赌局拿过去，要么怕了先卖。
- 一季交易几次，大多在上面那种几分钟里。

一年：
- 赢的卖得早，亏的拿得久（Odean 1998，转述：散户兑现盈利的倾向比兑现亏损高约五成）。
- 交易越多，赚得越少（Barber 和 Odean 2000，转述：最频繁的那组年回报约 11%，市场约 18%）。
- 买的是吸引注意力的东西：大涨大跌、上新闻的（Barber 和 Odean 2008，转述）。
- 从不复盘。记得赢的，忘了输的。
- 和朋友、群里讲持仓：赢了说，亏了不说。

## 3. 核心行为洞察

三句话。

1. **他不按 thesis 交易，他按对价格的感觉交易，然后用 thesis 解释给自己听。** 跌了以后理由会悄悄换：「长期 AI 标的」变成「现在便宜」变成「总会回来」。因为理由从来没写下来，换了也没人知道。
2. **他最频繁的动作是「看」，最频繁的问题是「为什么跌、对我是不是坏事」。** 这两个动作今天都由价格和头条回答，所以回答的是情绪，不是他信的事。
3. **他的两种错是反的，但根是一个。** 没事的时候慌着卖（噪音当信号），有事的时候死拿（信号当噪音）。根是他没有一个写下来的标准来分辨「这次是不是动到了我信的事」。

所以产品的位置很直接：**站在他「看」的那个动作上，把看到的东西换掉。** 不新建习惯，借用他每天几十次的那个习惯。

## 4. 我们改的四个行为

| 今天的行为 | 为什么会这样 | 他以后看到什么 | 预期的改变 | 怎么量 |
|---|---|---|---|---|
| 红盘日冲动卖 | 跌了不知道为什么，头条吓人 | 打开先看到：「你信的四件事，今天动了 0 件。吓人的那条站在你赌注 1 这边。」价格在第二行 | 没动到他的注的红盘日，卖的人变少 | 红盘日打开后 24 小时内卖出的比例，按「注动没动」分开算 |
| 破了还拿着 | 理由悄悄换了，没人记得原来的 | 「赌注 2 从『起不来』掉到最底格，推它的是这份文件。你 3 月 2 日画的线就在这。」 | 注破了以后到卖出的天数变短 | 注落到他画的线以下之后，到他动作的天数 |
| 买之前不写理由 | 买是几分钟里的冲动 | 买之前问一句：「你押的是这四件里的哪几件？哪一格你走？」默认给一条线，他只确认 | 写了注的买单变多；冲动买单变少或变得更拿得住 | 有注的买单占比；有注和没注的持有天数 |
| 从不复盘 | 复盘要自己动手，没人想 | 到期自动来收据：「押对了 / 押错了」，和当天股价分开；年底一封信 | 复盘从零变成被动发生 | 收据打开率；年底信被截图的比例 |

财报周是第一行和第二行的集中版：「周三结算的是赌注 1 和 3，你押的是 1，现在站『对得上』；2 和 4 财报解决不了。」他知道今晚是在等两道有答案的题，不是赌一把。

## 5. 第一屏不是一段聊天，是「你的注有没有变」

既然要站在「看」的动作上，第一屏就不能是一篇回答。它是一张和持仓页一样常开的卡：

```
NVDA  206.84  −0.9%
你信的四件事         上次看以后    现在看        见分晓
1 Q2 数据中心收入对不对得上 910 亿   没变   对得上   8-26
2 中国区今年能不能从零起来           没变   起不来   明年 2 月   ← 你押了，线在最底格
3 Blackwell 放量后毛利率守不守 75%   没变   守得住   8-26
4 云厂商自研芯片开始吃份额了吗       没变   还没有   明年 2 月
今天 NVDA 的新闻 38 条，碰到这四件的 0 条。
```

它出现在哪，看入口：券商的持仓页（Robinhood Agents 那种地方）；锁屏的 widget；每天早上 agent 的一条定时消息（Robinhood 的 Loops 就是干这个的）；聊天里一句「我的注有变化吗」。四种都是同一张卡。

人怎么第一次到这张卡上，是入口的事，不是习惯的事。七种第一句话（「为什么跌」「还能买吗」「这条新闻是好事吗」「大 V 说得对吗」「财报前卖不卖」「AI 到头了吗」「看看持仓」）全都回到这张卡，只是先答他那一句。详细的入口表在第一版里，不重复。

## 6. 旅程：从第一次打开到第二年

每一拍只写他看到的一句话和改的那个行为。声音是记得他说过什么的清醒的朋友：平静、具体、简短、说真话。

| 拍 | 什么时候 | 他看到 | 改的行为 |
|---|---|---|---|
| 1 第一次 | 红盘日他问「为什么跌，还能拿吗」 | 「跌 1.6%，市场跌得更多。你信的四件事一件没动，吓人的那条站你这边。你押哪几件，哪一格你走？」 | 冲动卖 → 先看注 |
| 2 点开一条 | 同一天 | 「这条 2 月 25 日就开着。5-20 没变，7-10 的传闻没推动，7-14 没变。」 | 相信它不是现编的 |
| 3 注动了 | 某天 | 「赌注 4 动了，三件没动。推它的是这份文件这一句。你没押 4。」 | 噪音和信号分开 |
| 4 结算 | 8-26 | 「赌注 1 结算：实际 X，落在『对得上』，你押对了。股价今天 +Y%，分开记。」 | 复盘被动发生 |
| 5 托付 | 他愿意的时候 | 三级，默认第二级：「通知我」→「问我」→「替我做」。「赌注 2 昨天 16:12 落到你的线，按你设的规则减了一半，成交 X。不认可可以撤回规则。」 | 出场从情绪变成规则 |
| 6 沉默 | 每周日 | 「这周 NVDA 新闻 38 条，碰到你的注 0 条。我没动。」 | 不看价也安心；「我没动」进记录 |
| 7 复盘 | 第 90 天、年底 | 「14 注对 8 注。对的里有 5 注是大家慌的时候押的。最常错的是毛利率。你画的线被碰到两次，两次都没反悔。」 | 知道自己是哪种投资者 |
| 8 授权变大 | 第二年 | 「agent 按你的规则动了 7 次，每次有理由，你一次没撤回。预算从 5% 提到 10%？」 | 信任凭记录变成钱：north star |

两种出场要分开说清：**按理由出场**是我们的（注落到线）；**按亏损出场**是券商和 agent 的（最大亏多少）。第一屏要写明「你的注没动」不等于「你不会亏」，不然就是假的安心。

## 7. 哪一刻是 wow，怎么量

不用形容词，用他做没做一件事：

1. **第一个红盘日他没有卖。** 打开，看到「0 件动了」，关掉。量：红盘日打开后 24 小时内的卖出率，有注的用户对没注的用户。
2. **第一张收据他截图了。** 量：收据分享率。
3. **第一次「你赚钱那次判断是错的」他没有关通知。** 量：复盘信之后 7 天的留存。
4. **他把第二只、第三只股票也放进来了。** 量：每个用户开着的注的数量随时间的变化。留存的单位就是开着的注。

## 8. 诚实的风险

- **假的「没事」。** 状态是模型判的。它漏了一条要紧的证据，用户看到「0 件动了」就拿着亏下去。这是这个设计最大的风险，比任何功能都重要。所以时效和分层是硬要求，而且第一屏必须把「按亏损出场」留给券商，不能让用户以为我们管了全部。
- **交易量可能下降。** 没动到注的红盘日他不卖了，按量吃饭的平台少了一笔。换来的是留存和加仓。净效应没数。
- **新手不会写注。** 默认给一条线他只确认，能解决一部分。没测过。
- **模型拆错了四件事。** 整张卡看着就是假的。先决测试：拆出的问题和卖方在吵的对得上几条。
- **每个拿 NVDA 的人卡都一样。** 个性化只在押哪几件、线画哪。够不够，要看第 7 节第 4 条的数。

## 9. 对 Hivemind 的直接要求

第一屏那张卡，每一栏对应 Hivemind 的一个口：

| 卡上的一栏 | Hivemind 要给 | 今天的设计 |
|---|---|---|
| 四件事和「现在看」 | 一个对象开着的观点和状态 | 有 |
| 「上次看以后」变没变 | 从某个时点起的状态变化，带推它的证据 | 要加：变化当事件给出去 |
| 「碰到这四件的 0 条」 | 这段时间进来多少条、连上观点的几条 | 要加：处理记录对外可读 |
| 「见分晓」 | 到期日 | 有 |
| 「实际 X，落在哪格」 | 到期定格，对着真实数核过 | 要加：代码核 |
| 「这条 2 月 25 日就开着」 | 观点的历史 | 有 |
| 「吓人的那条站你这边」 | 依赖：主题观点到对象观点 | 有 |

卡上**不**在 Hivemind 里的：他押了哪几件、线画哪、预算、通知级别。这些是「注」，记在 Hivemind 上面那一层，谁、哪天、哪条观点、押哪格、线、预算。用户押的、大 V 说的、agent 执行的，都是同一个东西。收据 = 注 × 定格。

## 10. POC 对着行为验，不对着好看验

| 验什么 | 怎么做 | 过的标准 |
|---|---|---|
| 拆出来的四件事是不是「他的」 | 只用 7-24 以前的材料写 NVDA 的四件事，做成第一屏给 Alex | Alex 十秒内说「对」；和当时卖方在吵的对得上大半 |
| 红盘日那张卡说得对不对 | 7-24 到 10-22 按天喂材料；NVDA 单日涨跌超过 3% 的每一天出一张「动了几件、哪件、哪份文件」 | 每一天的「动了 / 没动」事后看是对的；证据到状态延迟几天 |
| 结算说到做到 | 8-26 到期的两件对着财报里的数定格 | 定格的格和财报的数一致 |
| 假的「没事」有多少 | 回放里，状态说「没动」但事后看该动的那几天 | 数出来，这是这个设计最重要的一个数 |
| 他会不会押、会不会截图 | 用 Alex 在第一屏真押的注和线，走到第 90 天出复盘 | 他押了几件；复盘他想不想发 |

顺序：第一行 → 第三行 → 第二行和第四行一起 → 第五行。

## 11. 五年后，一段话

agent 从替你下单变成替你持有信念，拿的是一份 mandate：信什么、什么会改主意、多大预算、多久。Robinhood 已经把公司 KPI 做成了合约，顺着走，你能只持有一只股票里你信的那几件事，不信的那件对冲掉。理财从按风险等级配 ETF 变成按信念和记录定 agent 的权限，mandate 随记录长大。结算记录变成判断力的信用分，大 V 被有记录的人取代。预测市场是钱那一侧，Hivemind 是证据那一侧，两边的差是 edge，散户第一次和专业的人看同一块板。Hivemind 在这里不是 app，是人、agent 和合约谈论信念时共用的记忆。

## 12. 要 Alex 定的

1. 目标用户就定「有故事的持有者」，短线和被动的不管？
2. 产品的位置就定「替换看价格的那个动作」，第一屏是那张卡，聊天只是入口？
3. 第一版先做哪个入口：券商持仓页 / agent 的早间定时消息 / 聊天。我倾向 agent 的早间消息，因为它天然是「每天看一次」，而且 Robinhood 的 Loops 正好是这个形状。
4. POC 按第 10 节的顺序做。
