## 1. 建什么（不是新规则，是标准 5.1–5.3 的同一套话换成模型必须填的字段）

每条证据先填三个字段（schema 里的枚举，带例子，排在引文前面，模型先表态再抄引文）：

| 字段 | 闭集 | 出处 |
|---|---|---|
| `party`：这是谁的说法、数字或动作，按它和公司的关系 | company / customer / supplier / competitor / partner / regulator / analyst_or_outlet / unrelated | 5.1 四类的主语：第 (1) 类 = company；第 (2) 类 = customer、supplier、competitor、partner；第 (3) 类 = analyst_or_outlet；第 (4) 类 = regulator；D250 第 2 条的"蹭文章的邻居" = unrelated |
| `news`：它带来什么 | new_step / new_figure / forecast_or_plan / policy_step / judgement / retelling / background / product_detail / market_move | 5.3 和 D250 第 1 条（重讲、背景）、D243 第 5 条（常识）、第 3 条（产品细节）、5.3 的股价行；D243 第 6 条（仍有效的指引、预测、计划按本来分量 → forecast_or_plan） |
| `scale`：它给了什么 | size / date / name / none | 5.1 第 (2) 类的"with a size, date or name"；D240（缺金额不是单独的理由：只对第 (2) 类是条件） |

留不留的规则（代码 `extraction.evidence_rule`，只对带字段的答案；就是标准的话）：
- `news` 是 retelling、background、product_detail、market_move 的 → 不写（理由 `not evidence: <news>`）。
- `party` 是 unrelated 的 → 不写。
- `party` 是 customer / supplier / competitor / partner 而 `scale` 是 none 的 → 不写（第 (2) 类的条件）。
- 其余都写；分量由判断定（D240）。

去掉的：角色说明里的"走一遍、归类、对清单"那一段和整张拒收清单（它们的边界变成字段值的说明）；请求末尾的复核清单（review，4,464 字）整块不再附。加上的：三个字段的说明约 2,600 字、
一段规则约 600 字。净减约 3,700 字。
