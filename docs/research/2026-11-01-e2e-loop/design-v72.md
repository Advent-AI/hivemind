## 1. 建什么

```
现在（poc-v91：D211 抽取不看库；D207 另一次放题调用）        v72（poc-v92：一个决定者）

  文章 ──► 抽取（只看文章）                                   当天开始时开着的题（按天快照，D251；含种子，D253）
            │ 说法（不挂任何题）、候选                           每题一行：编号、对象、到期日、问题
            ▼                                                  + takes 行（代码写的"这个文件收什么"，placement.takes）
   放题调用：说法 + 题的 takes 行（不看文章）                              │
      最窄的题；没家 → 扔                                                ▼
            ▼                                                文章 + [Open questions] ──► 抽取（role-v66 的正文 + 一段"题在哪、怎么挂"）
   匹配：候选 对 库里的题（合并 / 新开）                                  │ 说法：links = 收它的最窄开着的题的编号，
            ▼                                                            │        或自己候选的编号；都没有 → 扔（no home）
   写库                                                                  │ 候选：文章提出就提，已开的由代码并入（规则同 v53/v66）
                                                                         ▼
                                                              匹配（照旧）──► 写库（照旧）
```

一句话：放题员的那本规则书（takes 行）和那个判断（"这句话算不算这道赌注的证据"）搬到抽取手里，抽取拿着整篇文章做这个判断；放题调用没了。
