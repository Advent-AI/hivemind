## 2. 流程（AGENTS §7.3，一类一臂）

1. **普查**（$0）：被扔 / 没开 / 重复的每一条列出来，按机制分类，取最大的一类（`harness/dropped_census.py` 是放题这一类的普查）。
2. **机制**：追到那一句规则、那一处代码或"根本没有题可挂"；问模型本人（续存档对话）。
3. **$0 证明**：存档请求改一处重发或存档决定重放，看决定性的那几条翻不翻。不翻就不发。
4. **预测**（发送前写死，含零假设：同一配置两次发送差多少）。
5. **发**：三遍，`harness/run_arm.sh <臂名> <遍> <配置> [种子]`，对照是同一窗口已有的三遍（`poc/data/e2e-v83-seed-d1..3` 是当前对照）。
6. **读**：每条回归读到原始答案；盲读只在验收时做一次，不是每臂。
7. **记**：`log.md` 一行：假设、改了哪一处、数字（回归先报）、读到的、留不留、我的错。

## 3. 范围护栏（防 scope drift）

- **在范围内**：放题的召回（家的供给 = 题；放题规则；没家的说法怎么处理）、题的身份（D248 第 2、3 条）、判断的金标和尺子。
- **不在范围内**：抽取提示词的措辞（v53 默认、v66 候选都够用，杂音在到达判断的里面占 13%，不是最大的洞）；UI；服务；三个月全跑（验收时一次，Alex 点头）；成本。例外一处，按 D255：抽取 schema 里 `one_line` 字段的定义（摘要点出归属的事项），因为放题自己那份核心损失的三成在这里，放题措辞修不了；它作为臂 3 之后的一臂，按抽取改动的量法量。
- 一臂一句或一条规则；一臂动了两处就不知道哪处起作用。
- 一个臂只准动它瞄准的那个数；别的数动出零假设就是回归，先诊断再发下一臂。
- 不为了凑数再发对照；对照已有三遍就用它。
- 任何新规则先对 D207–D209、D240、D248、D253 读一遍；和它们冲突的先记成给 Alex 的提案。
