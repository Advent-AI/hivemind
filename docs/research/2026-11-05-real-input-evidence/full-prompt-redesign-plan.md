Alex requests a complete line-by-line review and restructure of extraction prompt against actual PRD and analyst principles, rather than another case-fitted financial sentence. The audit is `full-prompt-audit-2026-11-05.zh.md`. Work remains in isolated worktree; original v74i, its request schema, the four frozen rulers and production default stay byte-for-byte unchanged. ## Purpose and proposed change

One new experimental role prompt reorganises the model's work into: (1) read the entire supplied article and identify material information against the signed standard, regardless of whether a question is already listed; (2) consider the important issues the item raises, and propose candidates when they satisfy the existing standard's admission rules, including value-carrying annual quantities; (3) connect each retained statement to a relevant shown or same-answer candidate under the existing `links` schema. If none, leave links empty and existing code drops it. Existing filters, closing check, schema, question snapshot and model settings stay unchanged. A draft user group instruction resolves the D165 contradiction and a draft T5 category instruction states actual-versus-guidance source tiers; other category content is unchanged. Keep examples and standard evidence boundaries; do not add metric/company-specific lists. Correct the local apparent contradiction `A material statement is one of four kinds` versus `four kinds ... do not decide what is kept`, by saying those are common forms and the analyst materiality test decides. Explain in the opening paragraph and candidate section that “a number alone does not open a question” means individual numerical occurrence is not sufficient, not a prohibition on an investment-relevant annual forecast. Existing independent investment significance and current/next-year limits remain. User-approved D371 means relevant present and future financial information can be evidence for related questions; the user's separately approved sentence says financial information can be evidence regardless of period, while previously restated past actuals retain their optional boundary, but this does not authorize changing candidate year limits or opening a topic for every number.

Use the same actual `links` description: the narrowest relevant shown question plus any same-answer candidate it supports, including the existing same-quantity-other-period and company-revenue fallbacks; `narrowest_links` removes a broader linked question only under recorded dependency relationships, and does not enforce one link in all cases. Any statement still unlinked is dropped under D209. A prompt cannot read a day-start-excluded question; this limitation is not fixed. This can only attempt to improve extraction and linking; it cannot ensure no-home information is stored. The reason for reorganising rather than appending another rule is that the first paragraph currently tells the model to file evidence before describing the candidates it should consider, while model accounts cite the candidate restrictions when not opening/retaining a current or forward-looking annual metric. These accounts are retrospective and evidence of a plausible interpretation, not proof of a causal mechanism; request changes affect every answer, so do not attribute individual output changes to any one clause. Keep the closing prompt's no-repetition, noise, conditions, timing, relevant-third-party and source boundaries and all examples untouched unless a source-aligned independent review identifies an actual issue. The original role has 11028 Unicode characters; report new character and token changes, and justify any growth. No metric list acts as a materiality gate. The user explicitly requests full restructure, not only a one-sentence attribution experiment; hence do not claim individual prompt edits independently caused outcomes.
