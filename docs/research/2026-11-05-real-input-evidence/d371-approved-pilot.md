# D371 approved prompt: diagnostic plan

Alex reviewed and authorized this exact addition: `Financial information, guidance, forecasts and estimates can be evidence for a related question, regardless of their time period, including a question proposed in the same answer.` This adds 179 characters plus spacing because Alex explicitly requested this sentence; do not delete or rewrite another instruction to offset growth. It clarifies linking rather than opening questions. The schema already requires the narrowest relevant question, excludes merely shared subjects, allows own candidates, and provides a fallback for estimates in a different period. It does not allow attaching unrelated financial statements to every question. Insert it as a separate sentence immediately after the existing `A number, a financial line, a target or a named customer project ...` bullet, before `For every candidate`. Existing v74i is frozen; use a separate experimental prompt file and an isolated harness, not a default change. No historical ruler or gold changes. Compare exact request bodies except the added sentence.

## Prior evidence and limits

40 stored answers contain 163 evidence and 64 no-home handover drops in 15 articles; not all of those drops are errors. In Microsoft archived response 116, e11 (current next-quarter guidance) and c1 (annual revenue candidate) co-occur but e11 has empty links. Changing only its link to c1 in a copy passes source checks and handover; this does not demonstrate the modified prompt or matching/judging. Re-sending the unchanged request once produced neither e11 nor c1, so co-occurrence itself varies. An NVIDIA fiscal 2028 question existed earlier on the day but was excluded from the day-start snapshot; this pilot does not fix that. Article dating has not been fully verified.

## Fixed diagnostic population and predictions

The four fixed source IDs, original archived request identities, wire-order hashes, source hashes and snapshot are in `d371-financial-link-pilot-design.md` table, used only for input identities and hashes (its different prompt proposal is not used) (archive calls 116, 99, 11, 15). Verify each before any send. Use real item text and the seq 1204 day-start library; no extra earnings report and no preset question. Four articles × two arms × one draw; control and treatment are both newly sent on the same day. This is a mechanism diagnostic, not acceptance or effect-size estimation.

A human reads all eight outputs against full article texts, checks every dropped financial item and every new/changed link for source, amount, period, attribution and reasonable relevance. A source-unsupported figure or attribution, an unrelated link, or losing a previously captured material statement is a regression; complete the already fixed diagnostic, record every regression and do not promote. Check that the specific relevant question is not bypassed in favor of a broader one. No promotion on the four-case test alone. Compare complete traces, not only counts. If no candidate and evidence co-occur, report that the test could not judge the link rather than a pass. Model sampling and a single draw mean neither success nor failure estimates efficacy.
