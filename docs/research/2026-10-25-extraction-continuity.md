## 已有证据与本次改动

两臂都给已提交的组及成员问题；唯一可控差异是角色文本。它们读取各自之前的结果，随后上下文的差别属于处理效果。既有原答可证明对象限定会漏掉四条项目上下文；本轮并不另证明全库搜索能力。小库全部组可见是刻意控制，不声称大库召回已解决。

role-v5 强制三个数字类别各开，事件却要求官方期限；T7 承认传闻，T8 要读分析师论证，两者与该入口冲突。schema 本来容许事件和两格答案。新角色取消这两个额外门槛，明确研究检查日不是来源承诺，保留数字年度限制。键、证据来源和组引用都由后续代码读取，未删。组文字不改，不增加事后聚类调用。来源仍为整篇原文。旧角色 2630 字，新角色字数、请求长度及实际输入 token 由本轮产物记录。缺失角色文字不能靠检索补回；遗漏来源语义也不能靠强制合并补回。

## 状态 × 事件

| 状态 | 事件 | 转移、写入与日期 |
|---|---|---|
| 未开始 | 预检和设计审查完成 | 新目录冻结配置、全文、角色、源码摘要；保存原 publication_day |
| 输入到达 | 首篇、后篇或跨对象 | dispatch 分配顺序号；抽取读本库已提交的组和问题；按输入日解释期限 |
| 已抽取 | 合法、无候选或只增证据 | 相同 sift 和 matching；当前 publication_day 与 seq 写入 |
| 检查拒绝 | 初次或再次要求恢复 | 保存原答，停止该序列；不重试，其他独立序列继续 |
| 调用中 | 外部失败、崩溃、到期仍在途 | 保留已预留费用，停止整轮；不自动重发 |
| 写入中 | 成功或异常 | 同一事务写观点、证据和组；异常回滚；不出现半条成员 |
| 已完成 | 重送或下一日输入 | 重送跳过；新输入读取已提交记录；历史按 seq 不改变 |
| 任意 | 配置/源文修订或另一进程 | 冻结摘要校验拒绝变更；独占运行锁；不混用两次配置 |
| 两个作用域 | 两臂或样本 | 独立库与 archive，禁止共享答案缓存；不同时请求 |
| 全部完成 | 语义通过或失败 | 固定逐项测量；失败报告根因，不自动推广或开下一臂 |
