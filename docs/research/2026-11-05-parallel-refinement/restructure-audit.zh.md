| A 候选、研究组、数字边界 | 现有输出及下游接收形状 | 保留规则和 schema，避免把新结构误当新产品设计；独立拆格式是后续待证假设 |

## 按标准追溯的新文字

- 先问影响收入、盈利、现金或信用风险、竞争地位：AGENTS §8、签字标准 §4 四个测试。
- 信息可直接或通过需求、供给、竞争、定价影响问题：标准 §5.1、§5.3 D250(2)、D369。
- 新问题要重要、独立、可公开核对，并对照题库：标准 §4、用户要求已有题库输入；最终是否相同仍由后续匹配判。
- 缺少市场预期或背景时不得编造：标准 §5.4 和 AGENTS §8；本任务不要求模型给出投资建议或推断未给出的共识。
- 一条消息不等于一个新问题；没有数字、日期或规模不单独丢证据：标准 §4、§5.2、D240、D371。
- 支持及反对同样保留来源、条件、时间与不确定性：标准 §5.4–5.5。

## 比较设计（准备中，非已通过）

同一真实文章、同一文章前已有问题与相同模型配置，比较旧单调用和新 A+B。单条证据按一个研究事项计数；冻结 gold 的 core + supporting 合计有帮助，not_kept 没帮助，optional 中立。原文、原始回答、检查后交接和掉落原因必须并排看。A+B 同一来源不能算两次独立确认；两路跨来源去重和真实后续写入尚未证明，不能用原始记录总数当收益。三次采样可比较波动，独立读者看含日期、来源、条件及归属的实际内容；题库来源必须标明历史快照限制。旧单调用必须原样作为控制，不把 B1 变体称作旧生产版。

先固定小样本、请求与来源的哈希、测试能改变的决定、预期和残余风险；离线检查 schema、实际提示、证据/候选 ID 与 handover，并按需要运行 preflight。完整 bench 或任何新模型调用当前都不能启动：`CURRENT_STATE.md` 明确暂停，三个开题金标问题尚待 Alex 裁定。任何后续计分仍须遵守冻结尺子，原文件不改。
