## Proposed field traced in both directions

- “narrowest … answer more or less likely … figure/step/estimate or demand/supply/competition/pricing”: D259/D264, signed §5.1. It neither mandates a link without relevance nor permits a same-name-only link.
- “compare specific … take that one only … never broader beside it”: D207/D264/D265. Audit any multi-home answer; the code does not fully enforce it.
- “shared company/industry/event/ecosystem not a connection”: D250(2); does not reject an indirect path with clear logic (D369).
- “whoever says it … missing amount/date not disqualifying”: §5.2, D240; tier and weight separately.
- “another period/population … when no question covers that period”: D268/D273; not an automatic link across every period. “A relevant quarterly actual or forecast can inform an annual question” is D371 and remains a relevance judgment, not an automatic link.
- “no specific question … company-wide revenue question of its period”: D273/D361, not a new fallback to arbitrary margin or unrelated subject.
- “a material assumption or condition … can inform same question … preserve uncertainty”: §§5.1,5.4 and D371. This is permissive, not a rule that every condition is material or independently informative. Its use does not fix a non-standalone evidence summary.
- “existing IDs only / empty if none”: user split and D209; no fake seed or forced candidate.

Prompt growth is confined to the B field owner because the split removed the original definition; quantify exact bytes/tokens after assembly. The failure class is traced above; causation remains a hypothesis. Another reader must check this audit and the complete frozen request before any paid send.

## Full-wire review and shared baseline corrections

The original B end check rejects market value without qualifying the covered company's value as optional, and does not explicitly say that a clearly restated past actual is optional. The experimental control and treatment both add these signed boundaries in the shared end check before the `links` field comparison; therefore this is not an unchanged production control. Still-effective guidance and forecasts keep their existing weight. The correction is not a requirement to retain all past actuals or valuation. The field treatment remains the sole difference between the two arms.

The unattributed reported Jalapeno comparison has an unresolved source-attribution question under the §5.3 distinction between competitor and third-party comparisons. The failure-class row above is a trace to inspect, not a settled scoring label: neither inclusion nor exclusion is counted as a treatment win until the attribution is resolved. Similarly, an indirect source fact is not excluded solely because its effect is unquantified (D369); it must still have a clear reasoned relationship to the specific question.

The common closing text also preserves §5.3's optional status for the covered company's share-price reaction after earnings. This is optional, and B still asks whether it informs an existing investment question; ordinary share-price movement remains excluded. This shared baseline adjustment and the two earlier optional boundaries are not the intervention being compared.
