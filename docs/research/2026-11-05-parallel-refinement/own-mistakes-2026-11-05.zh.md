# 我的错误与纠正 · 2026-11-05

Alex 指出，我让他花大量时间调试的是我自己错误的测试方式。以下是我的责任，不把它归咎于模型。

1. **起始状态错了。** 我曾把空库抽取当作有效的真实场景，后来又把未经完整来源时间验证的历史账本当作足够的起始库。正确做法：先确定测试日期，用该日期之前真实可获得的资料建立或还原题库，核对来源与时间，再处理测试期文章。旧的 22 道预设题被移除，不等于不要真实起始题库。
2. **评分逻辑错了。** 我把金标的值得追踪，当成文章出现时一定要新开，没先检查模型实际看到的库。正确做法：主题已存在且不重复开是正确；不存在且开了是正确。已有主题的证据处理独立验证。撤回之前把 GPU 金标题未单独提出直接认作漏开的结论。
3. **错把机械检查当质量依据。** 四篇实验只自动检查了结构和引文，并没有验证主题判断；历史匹配使用词汇重叠，甚至能将内存价格误配软件发布。以后明确区分结构检查和独立语义评判，不把它们叫作正确率。
4. **实验状态和产品状态混了。** 四篇实验用逐篇之前的题库；当前工作区回放是日初题库并按对象过滤。以后明确记录每个请求实际输入，比较两种方案时保证起始状态和输入一致。
5. **过度声称测试真实性。** 68 题库来源和原文可获得时间并未逐条确认；有历史页面混入后续标题的已知例子。我不能以“不是种子题”或数据库日期替代源头核验，也不能把未验证的状态叫作真实复原。
6. **结论给得太早。** 把单次输出和未验证的评分作为方案优劣，导致 Alex 要花时间纠正。保留历史输出与冻结金标，新增明确纠正，只有经源头、输入、测量和输出核对的内容才能作为结论。
