## 先测什么

对照是真实旧的单次抽取请求，实验是 A 新问题及其文章证据 + B 已有问题证据。三路使用同一文章、同一文章前的真实历史题库、同一模型和相同运行条件；不加入 22 道人工预设问题，不额外导入财报。两路的结果必须合并后和单次抽取比；不能将 B 的数量当全部召回。

## 每篇每次对比什么

1. 新问题：原文依据、是否真有独立的投资意义、已有问题是否覆盖、时间口径与实际可核对结果。
2. 有帮助证据：原文中的一个研究事项算一次；既有 gold 的 core 和 supporting 合计，not-kept 为没帮助，optional 中立。原文提及的来源、数字、条件、时间、预测与事实不能丢失。
3. 证据去处：比较模型原始输出、检查后交接和下游收下/丢弃原因；关联正确不由有 ID 代替。
4. 冗余和错误：同一来源在 A/B 各出现一次不能算两份独立证明；分别检查不相关信息、错引、未经证实的事实、错误日期和误关联。
5. 波动与成本：单次只用于诊断；拟采用同条件独立三次抽样并记录所有结果，价格按 `model.PRICES` 和 `CACHED_INPUT_SHARE`。是否需要每一轮取决于先前结果和未解决风险，不为凑数重跑。
