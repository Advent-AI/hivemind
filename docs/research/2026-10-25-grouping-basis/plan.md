逐字段读 D147 retained 的 12 份抽取原答和 D148 的 6 份原答：18 份、19 条候选观点、27 个归属引用、33 条证据、15 条新主线声明。检查的是 candidates[].thread_ids，不按标题相似度打分。完整读过各自的真实证据和最终成员。

已追到的路径：原答就写了错误/缺失引用 → 原校验只查非空、唯一、编号合法 → 原比对不再读这些引用 → 写入逐项保存。搜索给过正确的 Rubin 和 SK 范围，不能用扩大搜索解释这两个错归。原写入没有篡改选择。

## 最小实验形状

同一篇完整原文、同一 D147 sample-2 的前两篇状态，三份新鲜原版与三份新鲜实验版交错跑。原版是 D147，不含被否定的 D148 上下文变体。原角色、原文、已有主线和观点、模型设置、身份比对、写入不变。

唯一实验变量是归属的表达：把 candidate.thread_ids 换成 candidate.memberships，每项先有非空 basis（一句短说明），再有 thread_id。依据只解释候选观点已有证据与主线范围的关系，不另抄原句，不要求新模型判断或生成证据。自己的备忘录仍沿原规则处理，不新增“必须有外部证据”的限制。

新 schema 明列 basis 和 thread_id，additionalProperties=false。原来的 thread_id 正则、非空、唯一和已声明/已展示检查都保留。接到原答后先验证新形状，再按顺序投影回 thread_ids，交给原 retained.process。原答连同 basis 原样存档；比对和写入不读 basis，也不把它当证据。不得填默认编号、去重、补漏、修复模型原答。

替换原归组提示段，不往后叠提示。新段不长于原段；记录整个 system 的字符与估算 token。basis 在 schema 中排在 thread_id 之前，要求把选择依据写出来；不对外声称拿到了模型内部思考。

## 固定读法和停止点

开发案例沿用 Network World 的完整多年汇总页（2026-08-12，54,526 字符），明确不代表日常单条新闻。复用 D148 原文位置追踪 OpenAI、PC、风险的衡量方法，逐份读全部新增候选观点、证据、主线及 basis。

报告四件分开的事：抽没抽出；原校验留没留下；最终是否同一正确观点；成员归属对不对。没有抽出 PC 不算正确排除 PC。名字、额外合理组和组数不要求一致。核心出货 / SK、历史 seq2、重送也检查。

若实验出现错归、漏归、风险漏抽、拒绝，或反例没有被实际抽到，就不宣称修复，不自动追加样本。控制若也全对，只能说这个小样本未显示增益。不得修改旧衡量标准或新造总体百分比。

仅在三份实验都保留 OpenAI→Rubin、排除 OpenAI→SK、保留风险，且至少一份实际抽到 PC 并正确另组，同时控制暴露上述错误时，才启动预先指定的独立案例：nvblog:google-cloud-vera-rubin-infrastructure，原文与日期不变；同样从前两篇状态起三份原版 / 三份实验，检查独立的 Google 部署是否进 Rubin、有无无关成员。只测一次，不据其结果调方案。全部 Google 反例不足仍如实记未测到，不能称跨行业验证。

新实验总上限 24 次请求、$1 估算；每篇通常 2 次，必要时第三次也占同一上限。到上限就停，不补样本。D147 的 47 次/$0.641424、D148 的 12 次/$0.202629 和预算原样保留，不续写。沿用相同 provider、模型和设置。新结果不自动接入默认管线。

## 状态 × 事件

| 状态 / 事件 | 转移、保存和时间 |
|---|---|
| 未准备 / 准备成功 | 新目录存原文、原始前缀引用、配置和代码 hashes；旧记录只读 |
| 前缀重放 | seq1/2，用原始请求逐字比对后读旧答；不许为前缀发 HTTP |
| 新篇成功 | seq3，保留原 publication_day；同一抽取 → 原校验 / 比对 / 写入，一起提交 |
| 新形状或原规则拒绝、HTTP 失败、拒绝后重试 | 留原答和失败；该流停止，无替补，未知请求不重发 |
| 写入中途崩溃 | SQLite 回滚；完成的 HTTP 只许逐字重放；未知 HTTP 保留预算预留 |
| 已提交、报告未存 | 从同事务 ingestion_events 恢复，不重新调用 |
| 运行结束仍在请求 | 不记成功；原 180 秒超时规则不变 |
| 后来启动 / 配置变化 / 输入修正 | 每次核对冻结 hashes；不同即拒绝，不拿当天日期重算 |
| 两个写者 / 两范围 | 输出目录 flock；每份独立数据库，没有共享产品写者 |
| 完成 / 重送 | dispatch 必须 skipped；历史 seq2 与前缀完全一致 |
