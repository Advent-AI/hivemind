# 抽研究观点的分析师标准（2026-10-29；Alex 签字："1-5 都可以，按照这套标准来开始做测量，这条标准不要漂移"，D229）

> 已由 `docs/prd/05-extraction-standard.html`（第 3 版，2026-10-29 Alex 签字，D243）取代，这一份留作出处。

**一句话：一条陈述值得抽，是因为它改变我们对某个会动股价的问题的看法；一个新问题值得开，是因为它的答案能改变仓位、能在某一天核对、而且库里没有问题在问同一件事。其他的都扔。**

这份文件把已经存在、分散在七处的标准合成一份（§9 列出处），加上 Alex 已经拍过的判例（§8），标出还没拍的（§10）。它不新造规则。签字后它是抽取这一步（读一篇原文 → 证据和候选问题）的尺，金标和评测都照它改。

## 0. 一张图：同一篇文章，分析员怎么处理每句话

2026-07-06，fool.com 的一篇评论（`gnews:71df54965281684cc500960f`，T8）。一个资深分析员读完之后，每句话的去向：

| 原文说了什么 | 处理 | 为什么 |
|---|---|---|
| 华尔街分析师预计今年余下时间收入增长 82%，2027 年 41% | 留，核心 | 收入预期直接决定增长够不够撑估值。Alex 判 A。 |
| 管理层上次电话会预计云巨头 2026 年支出 6500 亿美元，2027 年超过 1 万亿 | 留，核心 | 客户要花多少钱，是需求的源头。"电话会上"这几个字不必复述。Alex 判 A。 |
| 分析师平均预计 FY2028 EPS 12.76 美元 | 留，辅助 | 远期盈利预期是估值的输入。时间远只是不确定性高，不是垃圾。Alex："可以留下来，只是太久远了"。 |
| 作者用 12.76 × 25 倍得出 FY2028 年末 319 美元 | 留，辅助 | 这是一条有假设、有推导、有时点的条件估值论证，留假设和推导，不只留目标价。**待拍（§10.1）** |
| 股价从高点回落 16% | 不留（可选） | 股价变动不是业务事实。可选背景：留不留都不扣分，说成业务恶化才算错。**待拍（§10.2）** |
| "我认为 2027 年底前能轻松到 300 美元" | 不留 | 作者自己的看多结论，没有新事实、新估计。 |

分析员的判断只有三个动作：这句话改变哪个问题的看法（留什么、多重要）；这句话必须保住什么意思（怎么写）；这篇文章有没有提出库里没有的问题（开不开）。下面按这三个动作写。

## 1. 我们抽的是两种东西

- **证据**（evidence）：谁在哪篇原文里说了什么。一条证据记录一句话或一件事，带原文引文、独立可读的一句话摘要、说话人、原始出处、层级（事实／当事人陈述／第三方观点／传闻）、原始日期。
- **候选问题**（candidate thesis）：这篇原文提出的、我们应该开始追踪的一个问题，带问题句、结果档位（梯子）、到期日、它靠什么公开材料结算。

抽取（第一步）只读原文，不看库（D211）。证据挂到哪个已开问题、候选问题是不是已经开过，由后面的归档和匹配步骤决定（D207、D190）。所以抽取的尺只量两件事：**该留的陈述有没有留、意思对不对；该开的问题有没有提、提得对不对。**

## 2. 什么陈述值得留

**规则一条：一个在追 NVDA（或任何在研公司）的分析员，读到它会在本周的笔记里写下来，因为它让某个问题的答案更可能或更不可能。** 问题不限于库里已有的，也不限于本公司：客户、供应商、竞争者、监管、宏观都算（D208 的七类驱动：需求、供给与投入、竞争与份额、定价与装机、产品周期、政策、资本与义务）。

四类（和 role-v18 起的提示词一致），每类两个例子：

1. **公司自己的数字、指引或决定**："数据中心收入 391 亿美元，增长 73%"；"董事会批准 500 亿美元回购"。
2. **客户、供应商、竞争者、伙伴的有规模、有日期或有名字的动作**："Sharon AI 六年协议，72 MW，最多 4 万颗 GB300"；"TSMC 说 CoWoS 产能 2026 年翻倍"；"Google Cloud 季度收入 248 亿美元，增长 82%，积压超过 5000 亿美元"（三个数是一件事，Alex 判 11）。
3. **具名一方的主张或估计**："SK hynix 说 2027 年是内存短缺最严重的一年，持续到 2030"；"SemiAnalysis 称 NVL72x2 过渡方案因客户反对被取消"；"分析师平均预计 FY2028 EPS 12.76 美元"。
4. **政策或监管的决定或步骤**："商务部批准 H200 对华销售"；"25 家公司联名反对过早限制开放权重模型"；"财长说将调查中国公司是否窃取知识产权"。

**预测、传闻、反证、远期、条件情景都是证据。** 它们的层级和确定性另记，不因为"还没发生""不是官方""离现在远""和我们方向相反"就不留。一个真实的风险反例可能比十个顺风数字更重要（gold v5 §一）。

**不留的**（每类一个例子）：

- 没有业务规模的产品、游戏、驱动、跑分细节："这张卡 415W"；"Geekbench 跑分"。
- 股价涨跌、投资人仓位、技术面："本月跌 13%"；"Burry 做空"。
- 作者的一般性风险清单和没有推导的看法："如果 AI 退潮会受伤"。
- 记者的背景和框架："A100 2020 年上市"；"海湾国家花了几十亿但仍依赖它"。
- 没有数字也没有决定的政治、战略表态："分散供应商不能减少政治依赖"。
- 同一事实的复述：一篇稿子用五句话说一个部署，是一条；三家媒体转同一个独家，各自那篇是一条，但原始出处写同一个（PRD 06-views：二十家转载一个独家是一个证据的二十个引用）。
- 已知事实的重述：两个月后再说一遍 Q1 收入、指引、已公布的回购；它是"旧证据的又一个出处"，不进本周笔记（stage34 gold 规则 A）。
- 模板：署名、作者简介、经纪商页脚、前瞻性声明、广告。
- 新加坡转运案件的概况和被告个人资产：原判 5：C 不留；D231 改为可选，收不收都不扣分（Alex："新加坡那条就随意吧"）。

**边界判例（Alex 已拍，§8 列全）**：竞争者的模型跑分（AMD 100 kW 机柜 2.4 倍）是辅助，不是不留；Omniverse 免费是辅助；三条开放模型政策各是辅助；Sharon 合同是供需的辅助证据，不是担保金额的证据；NVL72x2 取消归产品进度。

## 3. 一条陈述必须保住什么意思

必要的是**经济意思**，六格里只填这条用得上的（gold v5 §什么是必要原意，D220）：

| 格 | 要保住 | 丢了就错的例子 |
|---|---|---|
| 谁 | 原始判断者；是本人的估计还是别人的实测 | AMD 自己的模拟说成独立实测 |
| 什么 | 业务、指标或动作 | "收入增长 82%" 丢了"收入" |
| 多少 | 金额、比例、数量 | 四家 7450 亿写成五家 |
| 哪个期间 | 预测或事实覆盖的期间；"今年"按公司财年或自然年写都算对（D233），余下时间不改成全年 | "今年余下时间" 改成 FY2027 全年 |
| 什么条件 | 推导的假设；计划、上限、"最多" | "最多 4 万颗" 写成已部署 4 万颗 |
| 预测还是已发生 | 指引、预计、商谈、传闻 ≠ 已实现、已签约 | "商谈 6000 亿" 写成"已承诺" |

另外：原始发言日不知道就写不知道，不能填报道日（D220）；一条记录单独读要能懂，条件不能只放在旁边另一条里（D251）。

**不必要的**：转述机构（BofA 转述 AMD）、普通发言场合（"电话会上"）、付费方案全名。漏了不扣原意分；编造了仍算记录错误。

## 4. 分量：按投资后果定

| 等级 | 定义 | 例子 |
|---|---|---|
| 核心 core | 直接改变收入、利润、融资或信用风险、需求、关键产品进度的判断 | 收入增长预期；云厂商资本开支；内存短缺到 2030；Ohio 1050 亿担保；H200 对华出货开始 |
| 辅助 supporting | 支持或反驳上述判断，或给出可检验的估值假设 | AMD 比较；Omniverse 许可；EPS × 倍数的条件估值；政策表态；Sharon 合同 |
| 可选 optional | 帮助理解市场预期，省略不损害论证 | 财报后股价反应 |
| 不收 exclude | 模板、广告、与判断无关 | 作者简介；经纪商页脚 |

分量**不由**这些决定：数字多不多、是不是官方、离现在远不远、库里有没有页、和我们的方向是否相同、文章篇幅。"远"只影响确定性（D216）。

## 5. 三个判断分开，不能互相顶替（D228）

1. **来源层**（谁说的，能知道什么）：事实 / 当事人陈述 / 第三方观点 / 传闻。没有固定分数；传闻也能推动判断；一个独家被二十家转载仍是一个来源。
2. **研究用途**（它能支持多强的结论）：直接可用 / 有条件可用 / 线索 / 不可用（D221）。客户收入增长是需求线索，不证明 NVIDIA 订单；2028 EPS × 25 倍是条件情景，不是已实现结果。
3. **准入**（要不要开新问题）：§6。能不能开新问题和这条有没有研究价值无关：有价值但没页，记"问题覆盖缺口"，不记垃圾。

一条判断的错不能用另一条抵：传闻说对了仍是传闻；核心事实写成已发生仍是错。

## 6. 什么问题值得开（候选）

**规则：一个问题值得单独追，当它的答案可能改变仓位、能在一个日期用公开材料核对、而且库里没有问题在问同一件事。** 数量应该是判断的结果，不是目标（challenger §1）。

先问四件事（challenger 八条浓缩；每条可答是／否）：

1. **值得追**：写得出"这个结果会改变哪项收入、盈利、现金／信用风险或竞争位置"？写不出：留资料，不立题。"数字很大"不算理由。
2. **独立意义**：能写出两个情景，其他问题答案不变、只有本题相反，而业务判断确实不同？不能：优先作为证据挂到相关问题。
3. **能核对**：有一个日期和一份公开材料（年报、承诺附注、官方决定、发货确认）能把答案放进预先固定的档位？没有：问题要重写；"AI 前景良好"不是问题。到期没有材料记"未能判定"，不是失败。
4. **不是重复**：和已有问题比，只是预测值、措辞、来源、方向不同，最终核对的是同一个结果？是：同一题。不同的量、不同的期间、不同的决定才是另一题（D211 收尾的 D190 裁决集）。

**开题的四种理由**（D184，schema 枚举 `opens_as`）：主驱动量（承载公司价值的年度量，不是每一行财务数；也包括承载它的那代产品何时发布或出货，D236）；行业总量（一个日历年一个，另一口径、另一估计是它的证据）；政策阶段（主管方写明）；约束性义务（公司以自己名义为他人担保、提供融资、承诺购买、兜底，或写明规模且尚未完成的入股；公司自己借债不算，D236；已经承担的按下一次年报的金额开，D210）。

**不开的**：季度数字和指引；没日期的"护城河""战略"；高管任免、股东投票；例行诉讼程序；回购授权；客户的部署计划（它是供应商需求和产品问题的证据，除非改变供应商自己的现金或信用风险）；同一段指引里的每一行（费用率、税率是模型输入，不是争论）；把远期年度预测改装成事件。

**例子**：AI Compute Partnership（07-01）：NVIDIA 兜底云客户的 GPU 产能，有签约伙伴。开**一个**问题：NVIDIA 为此承担的义务在 FY2027 年报达到多少。Sharon、Firmus 各自的部署不开；"credit-support 义务""兜底敞口"换个措辞不再开（本周 v38 开了三页是匹配的错，不是标准允许的）。

## 7. 没有问题接的陈述

抽取不看库，所以它照 §2 写陈述；归档找不到家就扔，理由记 `no home`（D209，Alex："if it doesn't matter, just throw it away"）。评估时逐条读扔掉的，按"是什么机制该留它"分类：抽取垃圾 / 库里没这个问题（覆盖缺口）/ 页在却没挂上（归档错）/ 该开没开（准入错）。各归各的环节（gold v5 §四），不把一个环节的分数当整条管线的分数。

## 11. 尺子怎么量抽取（达标线提案）

**单位**：一篇原文里的一个研究事项（可由多条证据表达）。参照在任何发送之前写好并冻结（sha256），从原文写，不看模型答案；看过模型答案的文章只做开发集，留出集另取没看过的文章。

**每个参照项记四件事**（gold v5 §二）：选了没有（kept / omitted，拆几条合几条只算一次）；原意（correct / partial / wrong / absent）；可核查（引文和上下文够不够）；记录问题（原始日期、期间、归属、确定性、错来源、重复、推断未标明，各标 material / record_only）。

**分开报，不合成总分**：核心 N 项里 correct / partial / wrong / absent 各多少；辅助同样；误收率 = 留下的"不收"项 ÷ 评过的"不收"项；多留的垃圾按条数（我读，代码核结构）；每个 material 问题单列。分母为零报 not_exercised。三次独立发送逐次报，不投票。

**达标线（提案）**：
- 核心：每一次发送都 kept 且 correct，不带 material 记录问题（v18 验收用的就是"六篇五发每条都在"）。
- 辅助：三次里至少两次 kept，correct 或 partial。
- 不收：模板 0/3 留下（新加坡案件按 D231 改为可选）。
- 垃圾：每篇留下的无关陈述不多于 Luna 对照组的中位数（基线，不是目标）。
- 候选：§6 例子里该开的一个问题在每次发送都提出，且 settled_by 写得出；不该开的（部署计划、季度指引、同段每行）0 次。

不达标就读原始答案找机制，再改一处；不在读过的文章上调。

**结构由代码查**（免费）：schema 通过、引文逐字在原文里、每条一个陈述、候选的 due 在发布日之后。结构错不算内容错，分开报。
