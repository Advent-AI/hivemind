# 一份研究判断，后面的决定引用它

用户要求：失败不能停在报告，继续看trace、查原因、改善。范围仍为第四步研究实验，不改生产写入、抽取、检索或金标。

## 先查自己的上一改动

上次把完整准入说明加回提示后，NVIDIA两答都把“签约未知”写成“未签约”；其中一答还把已具名的Firmus写成建设方不明。19份完整回答有19个摘要、19个行动理由、9个另写的投资判断、2个论点段落。同一事实被几次重新生成，后面的目的从“读懂证据”变成“证明我能开页”。问题既有规则倒推事实，也有局部未知扩大成整体未知，不能只删reason就宣称解决。

本目录两个续问沿原请求和完整原答继续：模型承认把“未签约的处理规则”套用在未确认签约状态的材料上；承认Firmus具名；承认NN供应线索不要求先确认直接买方。自述仅是线索，原文和答案中的反例才是证据。此前55答的编号清点有1个虚构论点问题ID，16份实验请求都允许任意字符串；程序直到生成后才拒绝它。

## 一个结构改动

单次调用仍完成研究和去向建议，但只写一份note作为投资判断。取消另外生成的reason和independent_judgement，后续proposal引用这份判断。已存在问题的完整argument仍保留，不能用note代替D201要求的历史合并判断。未知限定到具体属性，不让缺合同金额变成没研究价值。

模型只选择本次实际存在的编号：有历史才展示comparisons、有目录才展示updates，并用enum限制引用；不存在的字段由程序补空。未知来源以每个比较的unknown表达，不强迫一个全局真假值同时表示独立性、首次来源和未证实来源。proposal可为null；有用不自动开页，也不因不能开页改成无用。四种准入及公开核验条件保留，绑定义务的未知状态不能作为合格准入。没有新增存储层或两次LLM调用。

对照是刚失败的D222整篇提示（不是冒称生产默认）。处理组换为一次陈述和显式引用的请求。整个变更是一个结构假设，不能分别归因文字、删字段和编号enum。既有D201投资判断、D184/D185/D210准入、D202/D204不删除证据、D220/D221衡量标准不变。

## 固定评价与发送

八个已见案例原输入原标准不变；新增真实NVIDIA8-K的空目录正例，作为提示定稿后锁定的检验。全文7015字符，来源明确2026-08-17已签残值保证、初始1050亿美元累计上限、约4.25GW，支付以履约条件等为前提且部分预计2028起生效。支持按下次年度披露衡量义务金额，不能因为2028才生效而写未签，不能当已支付1050亿，额外3.8GW是可选支持。空目录明确为构造情景，不假称真实历史状态；此例检验是否一律不提新问题。同时保留原G10全部71条历史，独立命名existing_signed，作为必须更新旧论点的正例：e1205/e1206明确已签和1050亿美元上限，应更新v25，不能混同芯片采购金额、不能把NY Post算独立确认。两例都在发送前固定，均不据测试调整提示。原预算用3倍输入量跨过计费档造成虚高；55次历史实测的count_tokens与实际输入完全相同，新预算仍用2倍输入+16384或请求字节数的较大者，远高于实测，并保持两轮合计$0.60上限。

每例每臂三次；先发NVIDIA、NN共12次做最便宜证明。若处理仍新增明确错误，停止扩展；否则其余八例48次，合共60次，不重发先发的12次。对照若不复现旧问题，不称已证明该原因；重复自己不稳定，不用一次翻转作胜利。预计全部发送包括2次诊断在$0.60以内，冻结前实际token计数预算，不提高上限。

按原D221四维读全部返回：目标内容、结论边界、来源/时间、必要追查；新输出不得靠附上原文冒充内容保留。note及完整论点必须实际表达关键内容和用途。关系和提案都算输出，不能藏到“元数据”中避开评分。主张是否正确与是否符合开页条件分开计；背景/空proposal不是拒收准确率；不给单一整体正确率。原八例本轮全属开发，两份签约正例只在配置固定后评分；同一配置不据测试改提示。

## 表和验收

| 状态×事件 | 转移与写入 |
|---|---|
| 准备×缺输入、缺参考、预算不足 | 不发，保留原因 |
| 冻结×发出 | 哈希验证；并发8；固定输入日期和历史快照 |
| 在途×成功或完整回答的结构拒绝 | 原答先保存；拒绝计为失败样本，完成同一预定批次，不重试 |
| 在途×API/截断/崩溃、再次启动、其他写者、配置变化 | 启动锁/哈希拒绝，不续费重跑 |
| 首批结束×证明不成立 | 留全体结果，不盲目扩展 |
| 首批结束×有改善且无新增错误 | 同配置执行剩余固定案例，最终逐答审读 |
| 结束×后来日期/输入更正 | 旧结果不改；新输入另作实验，不回填历史 |

| 写入值×读取者 | 新路径对旧检查 |
|---|---|
| note/limitations/follow_up×审读 | 沿用D220/D221；逐句核来源，非标签评分 |
| origin/comparisons×审读及后续研究 | 历史ID闭集；同主张不等于同来源；关系互斥 |
| updates×审读 | 旧完整论点结构，题ID/证据ID闭集；只有实际存在的问题 |
| proposal×审读/未来写入 | 明确准入类型和核验信息；本实验无生产写入；不能宣称修好最终挂接 |
| 省略的空字段×规范化器 | 仅补空列表，不补模型判断，不自动修复错误 |
| 原答/usage×预算和汇总 | 全计划槽位核账，原答哈希，任何缺失明列 |

最便宜证明至少要看到NVIDIA不再反推未签、NN承认现有供应线索用途；三个处理重复不能有同类或新明确错误。剩余案例无新错误才允许认为这是有价值的研究配置；不据一次小样本升生产默认。先38份旧答和19份D222重放验证既有拒绝，再用合法/非法ID及空目录边界验证新契约。预检结果与上一轮一致：98请求、841/831证据、13既有过滤、47匹配含1最终状态历史误报、286枚举齐全。

对已知模型错误不再让一次拒绝中止全部采样：它是需要测量的结果，仍算失败样本，不写生产。只有传输、用量、截断等实验条件失效才停发。首批结束仍严格按原语义门槛决定是否扩展。这修正D222把被测错误当实验故障、永远凑不齐三次对照的问题，不降低任何质量验收。

第一轮审查指出签约空目录请求复制了别例的引用枚举，已改成仅incoming，并将全体请求引用域作零费用核对；这是准备错误，未发模型。审查还要求必须更新旧论点的正例，保留完整G10满足它，不用空目录正例替代。
