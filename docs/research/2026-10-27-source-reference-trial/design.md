# 先分开测提示词和引用机制

Alex 在 D347 后要求继续修改、充分尝试，并允许适度扩展提示词。本轮是隔离研究，不修改生产来源合同或降低已冻结的语义标准。

例子：原文 `G42 ... CEO Peng Xiao ... has spent months` 被写成不存在的连续短语 `G42 CEO Peng Xiao`、`for months`。说的事可能仍对，引用却不能交付。一个新方案是把原文每个词编号，模型选起止词，代码复制原文；是否选对说话人和时间仍须评估，不能因复制成功就算语义正确。

## 已知问题与本轮假设

D347 全部 18 份回答的 616 个引用中，4 个无效字段导致 3 份整篇拒收。只改这四个引用，3/3 副本通过当前 writer，摘要不变。候选 CoreWeave 3/3 混合记者与专家，ROW 第二次有 10 条非时间短语进时间字段，比较与估值前提仅 1/3 完整。这些是本轮已有问题，不新增想象中的规则。

完整请求审计：旧提示已要求独立含义，不能再当成缺失；“合并相关内容”与“同一说话人”边界不具体；抄时间引用与生成自然摘要采用同一种自由文本，容易把原文改写；局部最小主引文不能单独承载跨段条件，但全文和时间引用可表达它们。schema 中的形状不再重复写成长规则。强化提示补具体的分句归属、条件比较、真正时间表达和出稿复核。增长有明确理由：Alex 允许，且这几类错误已经计数。保留原文，不把 gold 答案放进提示。

## 固定三臂

| 臂 | 系统提示 / 输入呈现 | 模型输出 / 代码 |
|---|---|---|
| control | D347 的候选原文 | 既有 `{paragraph,text}` 引用，原 writer |
| prompt | 新强化提示；原始编号段句 | 同上，单独测提示效果 |
| indexed | 同一强化内容；词带 `wNNN` 位置标签 | 引用改为 `{paragraph,first_word,last_word}`，代码精确回填，再过同一个 writer |

三篇 × 三臂 × 三次 = 最多 27 次新调用。gpt-6-luna low，12000 输出上限，轮换臂的发送顺序，每次最多两请求在途；每个响应独立记分。没有重试、投票、最佳样本拼接。全轮 20 分钟预算，单请求 120 秒。引用/JSON 失败继续剩余固定样本，网络失败停新请求。运行目录与代码冻结，脱离前台，有日志和 PID。

沿用 D345 总上限 $0.75；D347 后历史使用/保留 $0.403207，本轮上限 $0.346793。预算不足时停止，不能增额。比较沿用 14 论证、37 要求；三臂共 333 个要求机会，所有输出逐条读。重点新增比较的是选错词导致的语义损失，不让 indexed 臂因引用总能复制而获得虚假优势。

## 引用 I/O 与接受集合

词由标准库 `re.finditer(r'\S+', paragraph_text)` 按源顺序编号，编号在每段内从 1 起，句号仍是原来的 sNN。原文和字符位置从同一个来源产生。数字前缀是界面标记，不是来源内容。

引用只接受已知 paragraph、严格整数（不接受 bool）、`1 <= first_word <= last_word <= 本段词数`。代码从首词 start 到末词 end 取原文；不纠正猜错的区间、不模糊匹配、不补缺失引用。标点属于原词。交付仍是既有 `{paragraph,text,matches}` 形状，整个回答继续整体校验。局部词选择不能跨段；不连续出处可选真实连续名字，不拼接姓名和职位。元数据、全文哈希与原句范围仍由原 writer 写。模型选同一句的不同词可区分不同说话人。

这只是引用传输方案，不能保证选中的人支持整条摘要，也不能证明时间角色正确。过短、过长、错误的人/时间必须按原语义标准记错。引用中的源文标点不因美观删除。

## 状态 × 事件

| 状态 | 事件 | 处理与写入 |
|---|---|---|
| 未准备 | 来源/旧预算缺失、接口离线测试失败 | 不创建可发送轮次 |
| 已冻结 | 代码/请求/hash 改变、旧运行未结束 | 拒绝发送；不靠重启换样本 |
| 就绪 | 已过 preflight、有预算 | 预留后发送；不按今天填来源日期 |
| 在途 | 正常响应或结构拒绝 | 原文先存，原始答案与回填答案分开存；独立计分 |
| 在途 | 网络失败、崩溃、取消、超预算/超时 | 关闭新准入，保留费用；不重试，未评不算通过 |
| 已完成 | 发现缺陷、另一天/另配置 | 此轮不修分；新工作须新身份，保留所有失败 |
| 任意 | 另一写者/另一范围 | 只写隔离目录；冻结哈希不匹配则拒绝 |

## 值 × 读者

| 值 | 写者 → 读者 | 约束 |
|---|---|---|
| 原文、段句、词位置 | 同一 case → 请求、回填、原 writer、评审 | 原文不改写，词编号无语义 |
| 模型引用 | 模型 → 本轮适配器 | 只接受上述闭集，不从名字推断位置 |
| 回填引用/摘要/来源包 | 适配器/原 writer → 评审 | 摘要和角色不自动修复；保留 raw 以供对比 |
| 当前生产数据 | 原生产写者 → 生产读者 | 本轮不写、不迁移；research_context 也不变 |
| gold/评审/指标 | 冻结 gold + 助手读源 → 确定性计数 | 覆盖 333 项与全部输出，开发结果不是独立人审 |

## 新路径 × 原检查、先验证再调用

indexed 输出先检查合法词边界，然后回填成原 schema；旧 exact-key、枚举、引用、主引文、空段 XOR、全文/元数据检查全部执行。跨段必要条件仍由独立摘要和语义复核检查。离线重放所有 D347 答案：15 份原本可交付，另 3 份只用已记录的四字段人工修正副本；要分别标明，不能说新模型修好了。测试同句两说话人、错词/逆序/未知段落拒绝、词编号不进入原文；同句引用相同也不合并记录。预先读取代码和真实返回形状再写断言。

D345 的“代码算字符位置，不让模型猜位置”仍是原合同；本轮显示词标签供模型选择，字符位置仍由代码计算，是待比较的替代传输方案，不回写原合同。D62 的不投票、D347 的冻结 gold 与失败不补抽均保留。设计自查的主要风险是词标签增加输入且可能选错边界，已纳入三臂和逐条语义评价；无未定义的自动修复分支。
