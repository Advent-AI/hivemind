## 1. 规则

- **R2-a（D248 第 2 条，代码）**：事件类候选（measure event / policy_event）和一道开着的题被 Jev 判为同一件事（same_quantity_or_event ≥ 0.5，或 same_quantity_other_period ≥ 0.5，或判官答 same_question / same_question_other_period），对象相同、事件类型相同（或按 R2-b 是同一代的里程碑）→ **并入**，不论截止日；截止日是证据（记在那条证据上），不是新题。前题开着时**不接续**；到期未决的接续是拉取模式的活（D248 第 2 条原话"new work for pull mode"），不在这里。
- **R2-b（D248 第 3 条，代码）**：同一对象、同一代产品（scope_key 相同，或 Jev 判同）的 launch / shipment / deployment 是一题：候选并入开着的那道（题文不改；"问出货那一步"的措辞由开题时的候选决定，已开的不改）。
- **R2-c（判官的范围）**：R2-a/b 定下的身份是代码的，判官不覆盖；判官只裁键留白的地方（数字题的模型措辞 scope、"一个计划几个数"是不是各自会动）。这改了碰撞判官（D184–D194）"判官拆开即新开"的规则 → **要 Alex 定**；倾向是（判官拆开的 18–22 道里，launch 对 shipment、同一计划的几种金额问法，按 D248 都是一题）。
- 不动的：D210 数字题和事件题分开；D190 精确键；D197 共享量；M3 的四种各 1 道，留着。
