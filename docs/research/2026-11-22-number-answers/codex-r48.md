## 3. Why the zero-cost gate missed it

**The author of the passing answer already knew the checker’s rules.** The fixtures hand in the expected IDs, units and period spellings. The paid rehearsal’s clean answer goes further and uses an estimate inside a preselected rung, with no source calculation and an unavailable reference. That proves the harness can carry a conforming answer and that planted defects can trigger checks. It leaves unanswered whether someone reading the exact request could write a conforming answer without that inside knowledge. [Registered controls](/Users/lchingen/hivemind/docs/research/2026-11-22-number-answers/DESIGN.md:152) · [Clean rehearsal fixture](/Users/lchingen/hivemind/docs/research/2026-11-22-number-answers/paid_rehearsal.py:42)

The missed step was a **blind write-and-check using the exact outgoing request**. Give an independent writer only the system text, user text and schema. Have them encode real forecasts and then run their first outputs through the actual harness. For each refusal, ask the writer to point to where the request stated the rule. Read the check back in the other direction for correct answers it cannot represent. An evidence ID enum would have prevented the most common source mistake. The request already uses one for citations.
