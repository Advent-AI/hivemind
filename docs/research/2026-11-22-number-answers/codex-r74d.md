### 2. What must change before building

1. **Preserve the directory that actually occupies `--out`.** Suppose A is still checking its package. Someone mistakes its empty output folder for the crash debris described in the design and removes it. B then claims the same name. If A finishes first, its `rename` replaces B’s empty folder. If A encounters a refusal first, its `rmdir` deletes B’s empty folder. Errno 66 protects a folder containing a file. Both operations succeed in the empty-folder case. On this Mac, I recommend staging privately and using `renamex_np(..., RENAME_EXCL)` through Python’s standard-library `ctypes`, with refusal on filesystems that lack support. That removes the need to create or clean up a public claim. The decisive test puts a foreign empty directory at `--out` **after staging**, then verifies that publication refuses and that the same directory survives cleanup.
