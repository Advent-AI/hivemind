四个分母固定：

1. 留下的有效率：留下且有用、原意正确的记录 / 全部留下记录。
2. 有用信息保留率：留下且有用、原意正确的记录 / 回答写出的全部 M 记录。它不包括根本没写出的信息，不能冒充整体完整率。
3. 垃圾拦截率：丢掉的 J / 全部 J。
4. 丢弃正确率：丢掉的 J / 全部丢弃记录。C 单独列出，并报告把 C 算作可丢弃内容后的上界。
