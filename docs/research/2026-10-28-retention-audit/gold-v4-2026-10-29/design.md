# 范围与检查设计

本次只订立和检查研究评量资料，不改产品、提示词、默认模型或历史分数。依据 D214（不能用引文重叠代替语义）、D215（十一项裁定）、D216（远期 EPS 可留）、D218（允许明确标注的推断）；新裁定按本次用户授权记录为 D219。

| 状态 × 事件 | 处理与写入 |
|---|---|
| 参考准备中 × 原文审读完成 | 写固定来源、语义要求、判断依据；本版日期固定 2026-10-29 |
| 参考准备中 × 审读发现矛盾 | 修参考及所有对应校准例，再审同一维度；不发模型实验 |
| 冻结参考 × 新输出／重复输出 | 逐条判断或记未评；合并同一事项的输出 ID；不变参考 |
| 冻结参考 × 未列新事实 | 记 unreviewed；不得加入现有分母 |
| 冻结参考 × 用户更正／来源有误 | 新版本并公开分母变化；保留本版 |
| 任意 × 资料缺失／损坏／并发改动 | 校验失败，不出分；不覆盖旧资料 |
| 任意 × 中断／外部模型失败 | 没有完整评量就无分数；只读检查无需恢复产品状态 |
| 仅有抽取 × 缺少下游输入 | 下游 not_exercised；不能宣布整条流程成功 |

| 值 × 读取者 | 输入与要求 |
|---|---|
| sources 文本与散列 | reference 的逐字引文；审读者读全文；检查器复算散列 |
| reference 的等级／required／authority | 审读者作语义判断；检查器只检查字段、来源、题号覆盖；不用关键词作语义判断 |
| calibration 的记录与 expected | 审读者检查理由；检查器核对真实回答和结构；构造例明确标记 |
| 外部 assessment | 每个指定来源的参考项都必须填写；全部保留输出 ID 必须归到参考或 unreviewed；记录输出不能被无声跳过 |
| 汇总 | 核心／辅助分开；可选留弃不计错；误收只对明确 exclude；另列未评输出与 material 影响；不生成总体分 |
| 冻结 manifest | 只读散列检查拒绝标准原地变更；它证明版本一致，不证明语义正确 |

| 新路径 × 既有检查 | 本次约束 |
|---|---|
| 本版 vs 旧金标 | 旧文件和旧分数原样保留；不改旧 scorer 的输入格式 |
| 新校准例 | 真回答按存档路径、ID、散列核验；构造例不能算模型得分 |
| 多条表达同一事项 | 一项一个 assessment；引用全部相关 ID，不按条数加分 |
| 合并表达多事项 | 同一输出可对应多个不同事项；重复 ID 仅在单项内拒绝；不用引用长度判优 |
| 不完整或未知标签 | 拒绝出分；空分母显示 not_exercised |

最小证明：真实 Haiku 收入摘要保留正确原意，但时间字段 material 错误；真实 Luna 摘要错误否认收入指标；正确模板误收与错误内容分开；可选背景留／不留均无选择罚分。校准不是模型准确率。检查器规模限制为一个标准库脚本，默认运行不访问网络、不载入凭据、不修改资料。
