# 第四步：把原文与投资推断分成不同输出字段

2026-10-29，发送前。上一轮要求模型在自由文本中区分事实和推断，NVIDIA 样本 Haiku 改写组仍有 2/3 把未确认的信用支持提供方写成事实；原组有 2/3 明确这样写、1/3 语义含糊。改写组另一次没提出问题，不能算正确推断。[原始结果](stage4-fact-inference-results-2026-10-29.md)。这说明加一句要求不足以解决已见问题，不能证明哪句话造成问题。

## 单一假设

只改变新问题的 `independent_judgement` 输出结构：由一个字符串变成四部分：`source_quotes`（材料编号和该材料的逐字原句）、`investment_inference`（分析师判断，可推断）、`assumptions`（判断依赖的未确认条件）、`unknowns`（不能确定的事项）。模型先有可核查的来源，再形成投资判断；推断不因没在原文出现而自动判错。原系统提示、用户材料、其他字段、模型、动作和历史不变，四字段说明写在该输出结构内。原始对照与新结构做成相同语义任务；不是向模型提供正确答案。

逐字检查每个来源编号与原句：`incoming` 对应目标记录的 `quote`；`item:e...` 对应该篇其他记录的 `quote`；`e...` 对应历史记录的 `quote`；`source_article` 对应给出的全文。每个引用必须唯一匹配请求中的一个编号，引用文字必须非空并逐字属于该编号的文本；`propose_new` 必须有一条来源原句和非空投资推断。其他动作允许四部分均为空。逐字检查只能证明原文存在，**不能证明它支持推断，更不能证明推断正确**；逐条人工模型阅读和来源比照仍是验收。既有 `same_claim_as/revises/opposes` 只接受历史编号的检查不变，本实验不修复同篇关系的错误。

## 参考、样本和通过边界

用[上一轮原设计](stage4-fact-inference-arm-2026-10-29.md)的四个开发案例：NVIDIA、NN、Corning、Sharon；以及[此前已固定但未发送](stage4-fact-inference-science-reference-2026-10-29.md)的 science 新目标作为来源阅读保留例。五篇均经过 v38 抽取，新目标此前未作为第四步目标；保留例的经济权重未由用户裁定。science 必须先发，防止前面某个格式错误使它再次完全未测试；同一模型同一案例的原结构与新结构分别三次。5 × 2 结构 × 2 模型 × 3 次 = 60 次，保守预留及最多八个在途请求不超过 $0.60。若格式、身份、传输或用量异常，停止新发送，已在途的结果保留。新旧每组分开记录完成次数、经济内容、事实及推断边界、来源和机器检查；不以多数投票覆盖错例。

主要观察：NVIDIA 文章未确定信用支持提供方；当新问题推断由 NVIDIA 提供时，是否明确写明它是推断并指出主体未确认，同时保留 NVIDIA 的产品收入和云收入分成；没有提出问题不能算正确。在用户确认的 Sharon 样本观察六年、72 MW、最多 4 万 GPU 的条件和供需用途，在其他案例保护其原文与主体。science 原文说 Anthropic 的 Claude Science 使用 NVIDIA BioNeMo 工具，不证明合同金额、用户数或 NVIDIA 收入；判断可能的生态作用允许标为推断，是否开页和经济权重不得自行当成金标。对照也逐条读取，3 次原对照本身若混合则只报告次数、不声称稳定修复。结构解析或来源引用失败算实验失败；目标没有展示、动作不确定和缺少相应判断都不计成功。该抽样和研究输出不能说明产品账本完整或全流程性能。

对 Haiku 的方向性要求：在全部已发且有相关判断的 NVIDIA 新结构答案中，不出现把谁提供支持当成原文已证实的说法；若认为 NVIDIA 是提供方，明确列作有条件的推断或未证实假设；来源原句存在且能支持所述来源事实。任一用户确定的必留含义相对新鲜对照明显丢失、引用无效或新保留例出现确定的事实错误，不能称该模型通过本组。控制组没暴露判断或问题没提出，记录无法判断而非通过。预先定义的内容用模型阅读标注，来源或相关性不能判断则标未知。若只有一次新目标样本，不将其称为广泛泛化。

## 范围与读写

| 状态／事件 | 处理 |
|---|---|
| 未启动；源、代码、标准改变 | 重新冻结，不发送；原文件不覆盖 |
| 已启动／回答正常 | 为每次尝试独占编号并记录实际请求、原始返回、解析及用量；历史读取用原保存的序号 |
| 在途／结构或用量、连接异常 | 不发新请求；等待已发请求并保存，明确未发送列表；不自动重试 |
| 已完成／次日或配置更改 | 本轮保存独立结果；改变配置需要新目录和新预算 |
| 同时另一进程 | 独占 worker 锁；不允许另一个 worker 使用同一目录 |

| 值 | 来源和读者 |
|---|---|
| 原结构与新结构、来源快照 | 同一冻结请求，模型、来源引用检查和模型阅读各自读取；不写产品 |
| `source_quotes`、`investment_inference`、`assumptions`、`unknowns` | 仅新结构模型写；研究解析器检查结构和引用，阅读者核对语义；产品没有读者，无法宣称写入 |
| 同篇／历史引用编号 | 源文本来自既有 reader 和已通过抽取检查的存档；既有身份检查照常通过，不把 `item:` 当历史关系 |
| 用量、锁、日志 | 复用已审核发送器；只用于本次预算及可追溯性；任何缺少用量停止 |

## 与原检查、既有决定的关系

D201 是未接入产品的第四步研究接口；D217 令 1–4 以用户给出的分析师判断为标准；D218 是 Alex 允许推断并要求自主继续。这个原型不改变 D201 产品约定、不改产品 prompt 或 model。原控制保持原 schema 与读取检查；新结构先过新 schema，再将 `investment_inference` 交给原检查，仅作兼容研究，另增编号及逐字原句验证。不接受空来源、未知编号、不同材料的原句；以实际请求和变异负例证明检查不是空跑。正式请求之前重放 v38 preflight；独立只读检查输入、用户标准、结构、预算与停止后再发送。模型输出费用和输入 token 数按供应商原始用量分别报告。
