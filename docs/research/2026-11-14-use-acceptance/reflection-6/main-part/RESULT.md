# The narrower main-part rule, applied by two readers at $0 (D634): it closes

**The rule:** "When a topic's outcome names several things, the main one is the thing its description asks about, if the description
asks about exactly one of them …; when the description asks about several of them alike, or about none, there is no main one."

**Who applied it:** a fresh read-only Codex reader and a Claude subagent, each alone, on the 26 topics in a coded order. The key is
outside the repository. Files: `reader-*.jsonl`, `compare.txt`.

**Agreement:** the two readers agree on main against none in 24 of 26 topics.

**Against what the gate's readers settled on the stored declines:**
- **Hugging Face** (T18): **both readers apply the rule and get "none"**. The description itself asks "Will Nvidia complete … — and at
  what final cost and regulatory conditions". Yet the gate's two families agree the decline is unjustified, and so does the source
  audit. **The rule turns a sourced wrong decline into a justified one.**
- **H20 and memory prices** (T19, T16): the rule gives the description's thing. Both readers mark that it overrides an outcome tracking
  equal things.
- **Reflection AI, equity commitments, Blackwell into China, CPO, supply commitments** (T24, T26, T03, T13, T15): "none" under the
  rule. Several are also marked arbitrary.
- **The two-year capex topics** (T17, T25): "none", so the justified declines are kept.
- **New declines:** Vera Rubin (T04) and Groq (T22) get "none" from one reader. On these topics the step today writes questions both
  families accept.

**Verdict, by the closing condition fixed in D634:** the rule overrides outcomes where it recovers a question (2 topics). It reverses a
sourced unjustified decline into "none" (Hugging Face). It would add declines where questions are accepted today. **It closes.**

**What this shows:**
- The readers' agreed verdicts on these topics do not follow any one textual rule of "description against outcome".
- Hugging Face's description asks three things, yet the readers judge closing as main, because the other two are details of the deal.
  That is judgement about what matters, not a text rule.
- By AGENTS §2 ("Code owns identity, never importance"), it belongs to the analyst's standard. With the sources silent (D631), it is
  Alex's ruling.
