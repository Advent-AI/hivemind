# One added field for this reading: `H` (read with `ladder/stage-a-reader-brief.md`)

Answer every field of the reading form as it says. Add one more field to each row, `H`: a list with exactly one entry for each part
listed in `other_fields.not_judged`, in its order (like `B`); `[]` when nothing is listed and for a `no_ladder`.

For each listed part, one of:

| Value | When |
|---|---|
| `part` | it is something the thesis's description or outcome names that the judged question leaves out: a second figure or event, a condition, a comparison, or a difference inside an outcome that no rung separates |
| `already_judged` | the judged question's own rungs already decide it: one of its outcomes or ranges is exactly this, so listing it as not judged is wrong |
| `settlement` | it names only where or how the answer will be known (a filing, a data source, a disclosure route), not something the thesis asks |
| `cannot_tell` | the item does not let you decide between the above |

Read the rungs as the judge is shown them (`ladder_as_the_judge_is_shown_it`) before marking `already_judged`: a rung decides a part
only when holding that rung says whether the part happened. Give the reason for any value other than `part` in `why`.
