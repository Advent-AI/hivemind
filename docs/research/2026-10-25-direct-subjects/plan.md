## 读完设计与代码后的结论

保留“持续业务过程”和“可判断的具体问题”两种身份。例如 Vera Rubin 推出是一件持续的事，2026 出货与 2027 客户工厂上线是不同问题。

阻挡来自三个位置：

1. 原 05/06 只交候选观点与证据，观点身份按对象、结果和时期判断；这是具体问题的正确边界，却不能兼作研究组的身份。D142 的三个样本均把抽取已指出的关系拆开。证据在 `ingestion_groups.py` 的原始请求与输出、D142 报告。
2. D143 把关联放在可省略数组，D144 上轮的三个新鲜控制共 9 份抽取答复全部 associations=[]。不能靠可选字段保证每个新问题有所归属。
3. D144 的 2 份返回匹配答复共 6 项全部自己指自己。`resolve_threads` 把这种答法当成图循环；两个流连第一篇都不能提交。第三份抽取超时，不是同一类缺陷。零调用副本只改这 6 个目标为空，两个流均能写入 3 个观点及 3 个组。这条路径已经证明：当前首要障碍是新增的编号图，不是数据库不能保存组。

本次还逐步核对了 `extraction.sift`、`matching.build_lists/check`、`writing.write` 和 `views/round.py` 的交接。组不能让不合格原句复活；候选观点的 evidence_ids 不能代替真实 evidence_links；合并进旧观点的证据仍要走第二次比对；只有 changed_views 或新增成员才改变组的内容。将这些保持为同一条原写入路径。

D144 的请求还把候选观点上的 thread_ids 与另一个 threads / thread_candidates 区块一起交给匹配。新请求保留原观点内容，但不让匹配重读已决定的候选归属；另设一个只含本篇业务组、已存组及各自可选旧编号的身份区块。抽取本身不变。

## 本次合同

- 抽取沿用 D144：本篇 threads[{id,name,scope}]，每个候选观点必须有非空 thread_ids。引用和原文检查不变。
- 身份匹配在原调用里新增 subject_groups[{local_ids,destination,reason}]。每项把一组本篇描述归为同一持续业务对象。每个保留的本篇编号恰好出现一次；不得为空、重复或遗漏。
- destination 只有两类：字面值 new，或本次搜索实际展示的库内 g 编号。JSON schema 动态枚举可选值，本篇 t 编号永远不是目的地。选旧组时，每个本篇成员必须在自己的清单里见过该旧组。
- 同篇同一过程的多个叫法直接列在同一项 local_ids 中，不产生指针，也没有主线图防环。新组的名称和范围取抽取顺序最早的成员；这是确定名称的规则，不是用字符串判断相同。不同描述是否同一件事仍由模型判。
- 代码生成每个本篇编号到最终身份的映射，复用原事务写入函数；候选归属由抽取唯一决定，匹配不能添加或删除观点成员。没有最终保留成员就不建组。
- 组详情沿实际 evidence_links 读取，并按所看顺序号过滤及排除已替代证据。无主线评分、摘要、层层嵌套或新的模型调用。

## 状态 × 事件

所有入库排序依分发顺序号，原始说话日期保留；不上电脑日历。

| 状态 / 事件 | 转移、写入与日期 |
|---|---|
| 空库，第一篇 | 抽取具体问题和持续过程；无旧组可选，匹配给直接分组，代码分配 g 编号；同事务提交。 |
| 旧组，后来不同里程碑 | FTS 从所有组找前 N 个；匹配可复用旧身份，具体观点仍走原规则，各自保存。 |
| 同篇多个过程叫法 | 同一 subject_groups 项接住多个本篇编号；按抽取原顺序定新组名称；无临时指针。 |
| 原筛选去掉候选或匹配不开 | 不建其成员；最终没有成员的组不建；其余照常。 |
| 候选归入已有观点 / 接续 | 先解析原观点最终编号，再存成员；合并后的证据仍走原第二次比对。 |
| 只有旧观点的新证据 | subject_groups=[]；组更新来自 changed_views；不重新猜分组。 |
| 重复原话 | 原证据增加出处；只有真的新增连线或成员才改变组。 |
| 主线匹配缺项 / 重复 / 未展示目标 | 整篇最终写入失败；原答留档；无默认组或补填。 |
| 部分写入时失败 | 原观点、证据、组、成员、完成记录一起回滚；分发的开始记录保留。 |
| 调用超时 / 拒答 / 进程中断 | 保存原状态，不自动重发；未完成不报通过；其余独立样本继续。 |
| 完成后重送同 input_id | 原分发 skipped，零模型调用，零新成员。 |
| 重新启动未完成目录 | 完成步骤沿存档缓存走；未知调用不重发；代码、配置、输入指纹不符拒绝启动。 |
| 晚到的旧文章 | 按本次顺序号写入；原证据替代由说话日期决定；不回改旧快照。 |
| 两公司 / 两范围 | 查找主线不按公司过滤；观点仍受对象名单检查；不扩大研究名单。 |
| 另一写者 | 本 POC 独立库单写锁，串行；正式多队列设计不改。 |
| 实验终态 | 保存全部样本及失败；固定标准判断，剩余预算不自动视为授权扩展范围。 |
