## 定位与最小改动

第一份直接分组输出有三个保留的本篇业务过程，却返回 subject_groups=[]。schema 只要求这个数组存在，没有表达每个输入必须归属；resolve_groups 才事后拒绝。第二份样本能交回三组，说明这不是没有办法表达，而是调用的任务和必答项没有收口。完成本轮全部固定样本后记录全量计数，绝不把失败样本补填成通过。

下一变体只换身份输出的表示：subject_choices 是对象，键是这次实际保留的每个本篇编号；每个键为必填，额外键不允许。每个值是 {group_id, reason}。group_id 的枚举是 new-1 … new-N（N 个本篇描述对应最多 N 个新组），以及该输入实际看到的旧组 g 编号。相同标签表达同组；new-1 只是新组标签，不指向 t1，没有递归或缺省值。空输入唯一可接受输出是空对象。reason 非空。

代码把相同标签的条目合成原直接分组格式，调用原 resolve_groups 和原写入器。对新组取抽取顺序最早成员的名称。这个转换只变表示，不补任何未回答的决定。模型原答保存为 subject_choices；处理记录保留转换结果。候选观点和证据的匹配输出不变。

## 状态 × 事件的新增行

| 状态 / 事件 | 行为 |
|---|---|
| N 个保留输入 | schema 必填 N 个键；每个输入在自己的允许标签中选一个。 |
| 多个本篇描述同一事 | 选择同一 new 标签或同一 g；代码形成一组。 |
| 新旧组标签混用 | new 与 g 不互指；各自独立。 |
| 缺键、多键、非法标签、空理由 | 整次答案拒绝，原答保留，事务回滚；不自动修复。 |
| 第一篇配对回放 | 重用刚完成的 direct 样本中的抽取原答，逐字核对完整请求相同；只重新调用变化的匹配。 |
| 后来的文章 | 沿各自数据库状态正常抽取、匹配、写入；不借用另一路状态。 |
| 重启 / 并发 / 预算 | 同一 run.lock 串行；保存新变体指纹和基线原答 hash；沿原缓存拒绝未知调用。 |
| 核心三个样本通过 | 剩余预算允许才进入预先固定的晚到卫星文章；否则清楚标为未做。 |
