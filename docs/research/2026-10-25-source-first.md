# 先选内容，再组织问题：最小对照实验

2026-10-25，D162。Alex 同意先检验 D161 提出的假设。本轮只做隔离实验，不更改产品默认配置、最终数据库合同或历史数据。不改 UI、Idea、分类、Pull、最终判定，也不扩大到上层投资论点。

例子：第一步读出“项目总成本超过 5000 亿”和“分析师认为这类融资风险很大”；第二步决定它们连到哪个问题。第二步没有采用某条时，必须留下原因。第一步本身也可能漏掉，实验分别观察这两个位置。

## 为什么试，以及不声称什么

D161 的全部 18 次抽取里，六次首篇有五次未写总成本；两次序列把 Ohio 归到 Rubin，形成三条错误成员；一条引文被改写后正确拒绝。两个问题都已在原答中出现，11 条成员和 66 次出处写入都对应交接。计数与原例见 `poc/reports/2026-10-25-extraction-evidence-01/results.md`、`audit.json`。已知正例是 grouped-1 首篇 e4；负例是 grouped-3 全部三篇；错组例是 grouped-2 首篇 c1→g1。

改提示词顺序没有解决这些问题。本轮假设：把挑内容和写完整问题分成两次调用，避免模型在挑内容时同时安排梯子、键和归属，再明确保存每条所选内容的去向，可能提高保留率和归组质量。这是对“分步加显式交接”整体的检验，不能单独把效果归因于多一次调用。没有声称已找到模型内部遗漏的原因。

不同时试原文片段编号：两臂都继续使用现有 quote 和出处字段、同一原文核对。也不改召回、模型、reasoning、组定义或误差标准。

## 闭合的交接合同

第一步输入：同一篇完整原文、原发布日和作者、类别读法、相同对象及研究参考、相同的已有问题简介。不给问题梯子输出要求或组选择任务。输出 `observations`，每条使用现有 evidence 字段，只有 `links` 留给第二步：`id/quote/one_line/speaker/original_who/original_day/tier/event_time`。id 必须完整匹配 e 加正整数且唯一。允许空数组，表示没有选到内容；这不是语义通过。

第二步输入：同一发布日、作者、对象、类别读法、研究参考、已有问题和组，以及第一步完整原答；原文正文不重复提供，不能绕过第一步自己添加事实。输出 candidates（不含 evidence_ids）、原有 threads，以及 dispositions。dispositions 是以第一步所有 observation id 为唯一必填键的对象；每个值只有 links 和 omit_reason。闭合条件只有两种：非空 links 且 omit_reason 为空；或空 links 且 omit_reason 为非空说明。缺项、多项或两种都不符合，拒绝交接。links 是唯一关系来源：代码从其中指向各候选的连接生成该候选的 evidence_ids，不让模型另填一份；已省略的 observation 因而不会成为候选依据。恢复后的 evidence_ids 和 links 必须满足双向一致，覆盖比对与写入两个读者。

代码按 dispositions 回填第一步原封不动的证据，形成现有 evidence/candidates/threads 形状，再过原有 schema、归属引用、sift、matching、writing 和组保存。引文真假和链接对象仍由现有检查判断，不复制一份宽松检查。被省略的内容只在实验调用记录中保存，不进入产品证据表。零 observation 直接形成空交接，不调用无事可做的第二步。

两步的请求、原答、call id 和费用分别存档；非空时最终交接指向第二步，并另记两步来源及费用合计。零 observation 时最终空交接绑定第一步的真实 call id 和请求摘要，只计第一步费用，来源记录的第二步为 null。恢复、重送和异常沿用隔离 runner 的规定：本轮不自动重发。整个输入成功写完才轮到下一篇。新模式必须由专用入口显式提供 reader；用旧单步入口误跑已登记的两步模式，在第一笔调用前拒绝。

## 状态 × 事件

| 状态 | 事件 | 转移、记录和日期 |
|---|---|---|
| 未开始 | 预检、审查通过 | 新目录冻结两个步骤、对照、代码和三个真实输入；保留 publication_day |
| 输入到达 | 首篇或后篇 | dispatch 分配 seq，读取本样本已提交的问题和组 |
| 读原文中 | 成功、有内容 | 存第一步原答；第二步读同一 seq 快照、原输入日，不写产品数据 |
| 读原文中 | 成功、空内容 | 空交接引用第一步 call id/摘要/费用，第二步来源 null；按原流程完成，语义检查不能因此豁免 |
| 任一步 | schema 拒绝或交接不全 | 留原答，停止该序列；其他独立序列继续，不重抽 |
| 任一步 | 网络失败、崩溃、到时仍在途 | 费用预留不释放，停止整轮；不自动续跑 |
| 已组织 | 合法 / 有证据被原检查删除 | 过原检查并记录每条原因，再匹配和原子写入；语义失败仍计数 |
| 写入中 | 成功 / 异常 | 观点、证据、组同事务提交 / 回滚 |
| 已完成 | 下一日或重送 | 下一篇读已提交内容；重送跳过；旧 seq 历史保持 |
| 任意 | 配置变动、修正输入、另一写者 | 冻结摘要或独占锁拒绝；两臂和各样本不共享数据库或缓存 |

## 值 × 来源/写者 × 读者

| 值 | 来源与写者 | 读者 |
|---|---|---|
| observations | 第一步模型 | 第二步、转换器、逐项内容审计 |
| dispositions | 第二步模型，schema 按真实 id 构造 | 转换器拒绝不全或矛盾去向；审计区分显式省略与第一步遗漏 |
| 原证据正文及出处 | 只由第一步提供，代码复制 | 原 sift、匹配、写入、后篇；第二步没有改写入口 |
| 候选 evidence_ids | 只由代码从 dispositions.links 生成 | 比对与写入读到同一关系；无第二份模型决定 |
| candidates/threads | 第二步 | 原归属验证及写入；不新增归组裁判 |
| reader 回调 | 新实验入口显式传给 runner | 仅实验臂 process；省略参数的全部旧入口不变 |
| 调用费用/摘要 | 原 Archive 与 BoundedTransport | 预算、复现与报告；包含第一步，不能只算第二步 |

## 新路径 × 原检查

| 路径 | 原检查如何保持 / 新交接如何验证 |
|---|---|
| 两步输出 | 转换后必须满足原 evidence/candidates/threads schema；unknown id、缺项拒绝；候选 evidence_ids 从 links 生成并验证双向一致 |
| 空内容或错误入口 | 空交接引用第一步真实来源；零第二步调用；登记两步模式但没有 reader 的入口在调用前拒绝 |
| 原文及来源 | 原 quote 核对不变；第一步有错照样拒绝，不能靠第二步修好后隐去 |
| 日期、梯子、身份 | 同一 sift、matching、writing，不改变字段或语义 |
| 两步调用 | 都经同一预算 transport 和 Archive；任何缓存命中拒绝；只有已返回的调用才能释放预留 |
| 第一步或第二步失败 | 真实 SQLite 验证零产品写入；默认单步入口及三篇连续入口照旧测试 |
| 审计 | 逐 observation 对照原答、去向、最终交接和来源；缺内容不能从分母消失 |
