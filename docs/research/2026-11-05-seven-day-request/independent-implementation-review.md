[Independent review](docs/research/2026-11-05-parallel-refinement/join-identity-independent-review.md:3)

It must preserve the actual A prompt, run real matching, write admitted results, and feed the resulting library into later days. Product extraction uses the **day-start** library: questions admitted today appear in subsequent days, while articles on the same day share the same starting snapshot. **Where meaningful frozen-gold scoring is possible**

The stronger existing seven-day window is **July 1–7, 2026**. Frozen `golden-v5-dev` contains **98 articles**, all present by ID in the experimental item database, with **25 must-open** and **35 may-open** question entries. These are article entries, not necessarily 25 or 35 distinct topics. This is a previously used development set, not a held-out test, and a verified library from before July 1 is still needed. [Frozen gold](docs/research/2026-10-29-ledger-standard/golden-v5/golden-v5-dev.json)

The prepared **August 29–September 4** feed has 486 items but only **two frozen-gold articles**, each with one must-open entry. It can exercise a seven-day flow, but provides too little gold coverage for a meaningful overall new-topic score. [Source census](docs/research/2026-11-05-seven-day-request/seven-day-source-census-2026-11-05.json)

Neither existing question scorer implements the requested judgment reliably: one scores whether a new candidate resembles the gold without checking the library shown; another checks an approximate library using word overlap and has matched a memory-price topic to an unrelated software-release question. [Scoring audit](docs/research/2026-11-05-parallel-refinement/measurement-context-scrub-2026-11-05.zh.md:30) Scoring must first assess whether the gold-worthy topic was already covered in the **actual input library**: avoiding a duplicate and opening an absent topic are the respective correct decisions. Evidence should be assessed separately: frozen gold’s core and supporting items count as helpful, not-kept items as unhelpful, and optional items remain neutral. An unlisted candidate is not automatically wrong.

**Source uncertainty remains material.** The August 28 snapshot has 68 questions with locally recorded earlier sources, but source version and library completeness are unverified. Historical page snapshots confirmed at least one creation quote for only 9 questions; 55 of 66 source lookup attempts had connection errors, which do not establish that snapshots are absent. [Source audit](docs/research/2026-11-05-parallel-refinement/own-mistakes-2026-11-05.zh.md:14) In the August–September feed, 14 timestamps fall after the assigned day and one body is known to have been updated later; some differences may be time-zone effects and require investigation. A stored July 2 page also contains October headlines, so a database date alone cannot establish what was available at the time. The July 7 Micron article has three frozen question entries whose specific scope is disputed; D373 says to score the unchanged gold and disclose the concern. [Gold concern](docs/research/2026-11-05-parallel-refinement/ruler-conflict-2026-11-05.zh.md:1)

That would expose the missing fields and handoff decisions before any seven-day run.
