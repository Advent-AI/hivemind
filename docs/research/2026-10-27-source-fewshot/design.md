# 四个完整范例是否改善来源抽取

本轮回答 Alex 的具体问题：少量输入/JSON 示例是否让抽取更准确。只测开发数据，不采纳生产改动。

例如，“某公司若在 2032 年取得 20% 份额，收入为今年三倍”，应保留假设、年份、收入基数；不能把“三倍”另写成无条件预测。范例使用虚构公司和不同数字，不包含三篇开发文章的答案。

## 已有证据与假设

D348 的文字强化仍有补年份、公司代词被当名称、独立比较缺条件等错误；词编号还会越界。因此继续沿原文本引用合同，测试完整正确输出能否比文字规则更清楚地传达边界。官方建议与请求审计见 [prompting-audit](../2026-10-27-source-reference-trial/prompting-audit.md)。

截至准备设计时，逐字段扫描 D345 final、D347 和 D348 已完成的 60 答案 / 1,197 段落，只有 D348 restofworld.2.prompt/p021 违反空理由/观察互斥（两者都空）。原 schema 没表达 writer 已有的互斥要求。这是生成格式与写入合同不一致，不是金标错误。最终 census 在所有 D348 答案结束后重算。

最便宜证明：在原始坏答案上仅改 schema，不改答案，旧 schema 接受，新 schema 拒绝；原 writer 同样拒绝。其余答案逐个对照，并测试四种空/非空组合。两组同时修正 schema，不能把此修复算成范例效果。

## 比较与预算

- 同一 D348 强化提示；控制组无范例，实验组加四对 user/assistant 消息。两组同加“前面的对话是示例，仅处理最后文章”的范围说明。
- 四例覆盖：记者/匿名专家/公司发言拆开且未知年份不补；跨段条件比较完整保留；软件迁移论据合并、重复跳过但反证保留；实际不完整期间与广告跳过。
- 仍是 gpt-6-luna low、12,000 output cap、同 schema、同正文、同 writer。3 篇文章 × 2 组 × 3 次 = 18 次上限，最多并发 2，20 分钟期限，无重试、投票或替换失败。
- D345 总上限 $0.75 不变，新 journal 上限等于扣除 D345、D347、D348 全部已用/占用。D348 完结且金额冻结后才启动本轮。
- 范例增大 token 有明确理由：原提示没有演示实际 JSON 中跨段指代、引用与合并的共同效果。记录字符、估算 token、API 实际 token、延迟和费用；不以提示短作为目标。
- D347 冻结的 14 论证 / 37 要求不变。222 个要求机会与所有输出记录逐条人工助手审阅；争议单列，不把争议当对。三次控制自身的波动一同报告，不外推到未见文章。

## 状态 × 事件

| 状态 | 事件 | 动作与记录 |
|---|---|---|
| 准备前 | 旧轮仍运行 | 仅离线准备；不启动新付费请求 |
| 已冻结 | 预检或示例不合格 | 停在本地，保存差异，不发请求 |
| 可运行 | 健康/预算通过 | 原 docs 路径启动，保存 pid/log；请求/代码/金标哈希冻结 |
| 请求在途 | 成功 | 原始回答先存，再 schema/writer 验证，存每次用量和状态 |
| 请求在途 | 格式拒绝 | 原样记拒绝，不重试，不把部分结果当交付 |
| 请求在途 | HTTP、断网、进程退出 | 停止；未知费用保留占用，不自动恢复 |
| 请求在途 | 20 分钟或预算不足 | 停止发新请求，等已经发出的返回，记录未发 |
| 已完成 | 后续发现错误、配置变化、输入修正 | 只补诊断；新请求属于新轮次，不覆盖旧输出 |
| 任一状态 | 并发编辑/第二写入者 | 本轮只读冻结副本；哈希不一致拒绝；独立 journal 不重启 |

日期来源是固定案例 metadata；相对时间仍保留原文。程序时限使用 monotonic，非日期推断。

| 来源输出 | 原 source_reading.materialize | 离线评审；不接入生产/DB/routing |

## 新路径 × 原检查

| 检查 | 无范例与有范例 |
|---|---|
| source 坐标完整、段落句子枚举、enum 数量 | 两组原检查；每个示例亦同 |
| 空理由互斥 | 生成 schema 前置，writer 继续复核；定义复用避免枚举膨胀 |
| claimant/null、引用原文、顺序、所有字段 | 仍用原 writer；无引用修复、无自动补全 |
| 独立意义/归属/条件/重复 | 全量助手阅读原始来源和输出；原金标不变 |
| 预算/真实请求/样本齐全 | 原 guarded transport、独立 frozen manifest；不得静默补样本 |

## 先前决定和范围

D345：“This does not adopt a storage migration or change production defaults or stages three onward.” D347：“No voting, retries, mid-run prompt edits or replacement of failures.” D348 同样是实验而非验收。D346 的旧金标不覆盖；本轮维持 D347 已授权的开发金标。只改研究脚本和报告，不碰冻结 PRD、生产合同、routing 或 Jev。

检查设计四表后：范例和测试文章使用各自 schema；示例不是最后 schema 的待输出内容；writer 的空白理由容许性用 whitespace pattern 保持；不把词编号 schema 带入。核心合同无未决项。
