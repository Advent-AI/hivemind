# 完整 JSON 范例的实测结果

范例改善了部分写法和本轮交付，但没有提升完整语义得分，不能说抽取已经可用。

例如，CUDA 的平台、开发者规模与迁移成本在有范例的两次输出中都保留在同一条；但 CoreWeave 的季度收入有两次仍漏掉“第二季度”，Motley 的估值有两次仍丢失独立阅读所需的前提。

## JSON 输出约束已经使用

D347、D348 和本轮都使用 API 的 `response_format.type = json_schema`、`json_schema.strict = true`，不是只靠提示词要求 JSON。实际请求见 [CoreWeave 有范例请求](../../../poc/reports/2026-10-27-source-fewshot/run-2026-10-27/coreweave.examples.request.json)。

Schema 已限制字段、类型、分类枚举、段落/句子 ID 及 claimant/null 的组合。它不能仅凭 string 类型保证 `text` 真在原文中，也不能保证选对说话人、年份或保留全部前提。`pre-date his estimate` 是合法字符串，却和原文 `predate his estimate` 不符，两轮都仍出现整篇拒收。

本轮补的是我之前漏掉的格式约束：有观察时理由只能空白；没有观察时必须有非空理由。两组统一采用，所以不能把此修复归功于范例。63 个历史答案 /1,281 段落中只有一个违反该规则；旧 schema 放过它，新 schema 拒绝它，原 writer 也拒绝它。四个示例和 24 个真假组合检查通过。

## 试验规模与完整结果

原计划最多 18 次，实际 16 次全部返回；在发 ROW 第三轮前，余下 $0.038520 不足覆盖单次最低预留 $0.039699，因此预算检查停止。ROW 两组第三次均未发，没有挑选样本或丢弃失败。两组各 8 次：CoreWeave 3 次、Motley 3 次、ROW 2 次。未达到每篇每组至少三次的完整实验要求；结果只能作为不完整开发诊断。

助手逐条审阅所有 408 条输出、198 个要求机会。原计划另有 24 个要求机会未执行，不能算通过或模型失败。金标保持 D347 的助手编写开发标准；没有独立人类裁决或未见文章测试。

## 哪些边界仍然失败

- 引用复述：无范例 CoreWeave 第一次、有范例第三次都把 `predate` 改成 `pre-date`；无范例 ROW 第一次还给 sold-out 状态制造错误时间引用。全轮三份拒收均保存。
- 名称解析：CoreWeave 六份答案的季度记录全部使用 `The company` 作为 named 引用；文字与示例没有修掉这类问题。
- 独立条件：无范例 Motley 前两次、有范例前两次估值仍缺前提或时点；第三次有范例才完整。无范例第三次的 then-current 比较基数有歧义，单列争议。
- 信息丢失：有范例 CoreWeave 三次有两次将第二季度写成一般季度收入；同组三次 Motley 还有一次把记者描述的竞争者动作归给 analysts。
- 重复：重复记录比例未下降，17/208 对 19/200。仅靠一个“跳过重复”范例，没有实现稳定去芜存菁。

上述 408 条逐项标签属于助手评审，不是客观无误的全量真值。来源归属与含混措辞可有争议，争议未算通过；[完整评审记录](../../../poc/reports/2026-10-27-source-fewshot/run-2026-10-27/manual-review.json)保留理由，便于重裁。

## 是否遵循提示实践

已核查 [OpenAI reasoning 指南](https://developers.openai.com/api/docs/guides/reasoning-best-practices#how-to-prompt-reasoning-models-effectively)与 [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)。适用建议是清楚直接的指令、分隔数据、必要时提供一致的输入输出示例，并用评估验证；格式约束不保证内容正确。

原请求有严格格式、来源编号和明确规则，但缺完整输出范例。这轮补四个不同失败边界的完整示例，不要求输出思维链。所有示例均为虚构公司/不同数值，不把开发集答案放进请求。

范例正文新增 4,962 字符 /1,172 估算 tokens；算入消息包装后，全请求估算增量 1,347 tokens。实际 API 两组输入分别 45,206 /55,094 tokens，即每份平均新增 1,236；输出分别 27,572 /23,962。长度可承受，但没有换来本轮完整语义提升。
