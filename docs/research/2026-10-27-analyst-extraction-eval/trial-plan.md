# 按确认后的分析师标准做一次完整开发对照

Alex 在评审材料呈现后要求：“你开始你的尝试/研究”。本轮按该口径冻结三篇文章的 14 个论证、37 条要求和提示词候选。旧稿、旧结果不改写。本轮是开发比较，不是独立测试集验收，不推广到生产。

## 固定实验

- 3 篇原文 × 当前来源提示词/新候选 × 3 次 = 最多 18 个新回答。两臂同为 gpt-6-luna low，输出上限 12000；只改变 system 内容。保留字节哈希、原回答和用量；不投票、不重抽、不选最好一次。
- 引用字段、全文、schema 及当前 materialize 完全相同。所有代码复制到新运行目录；发送前验证冻结哈希。代码继续整体拒绝不合格引用，不做边跑边修。
- 继承 D345 总上限 $0.75；四个历史 journal 已用/保留 $0.284681，新运行最多使用剩余 $0.465319。单次按旧保守公式预留，实际完成后记费用；无法预留则停，不提高上限。已有未知费用继续保留。
- 两个独立请求并发，每次等一对完成；交替两臂提交顺序。运行在独立进程中，日志与 PID 留档；网络失败关闭新调用，已在途调用完成后落盘。回答结构不合格是结果，不阻止下一个独立样本。
- 运行时间预算 15 分钟；单请求超时 120 秒，超时后不重试。启动前检查机器负载、磁盘、端点连通及凭证是否可读，不打印凭证。

## 验证与判读

先运行仓库 `scripts/preflight.py`，用源库的副本避免写原库；和前次同范围结果比较。另对全部 9 份同格式历史候选重放新旧两臂的共同结构检查，期望仍为 7 份通过、2 份引用失败。新提示全文审计和五份人工修正副本已在上轮完成，这些只证明表达能力。

记录以下独立指标，不合成一个掩盖问题的总分：

1. **结构交付**：18 份全部列出，完整、截断、拒答、引用拒绝各自计数。
2. **论证覆盖**：37 条要求在两臂各 3 次，共 222 个机会。对每条记录映射实际路径并判断 pass / fail / missing / disputed，附失败原因。pass 要求该条所需含义均被准确表达；已有别处同数值不自动过关。另按 14 个完整论证报告每次结果，不用“大合取全对”替代分项结果。
3. **实际输出质量**：逐条阅读原始摘要，识别支持且有用、冗余重复、缺必要上下文、来源/时间/事实错误及有争议。只对读过且有对应记录路径的输出计分。结构拒绝不能让未交付内容取得交付分。
4. **九类既有缺陷**：复核年份、期间、情景比较、机构归属、估值前提、说话人分离、CUDA 主体、实绩层级；未写比较不误算该比较正确。两臂共同失败仍是缺陷。
5. **资源**：每份输入/输出 token、响应时间、配置价格下估算费用；与源文大小和记录数并列。当前控制自己三次间的差异就是本轮波动参照，不凭 3 次推总体概率。

旧黄金集和基准库保持只读。本轮没有自动路由、新观点写入或最终模型判定，因此不报告去重/路由/投资判断的端到端改善。若结果仍失败，完整呈现最大的共同机制，不在相同冻结实验里追加新候选。

## 状态 × 事件

| 状态 | 事件 | 处理 |
|---|---|---|
| 未准备 | 输入或历史预算缺失 | 拒绝，不创建可发送请求 |
| 已冻结 | preflight 有新的拒绝/冻结哈希改变 | 停在本地诊断，不付费 |
| 就绪 | 请求可预留 | 日志记录后发送；读取来源日期，不用墙钟造事实 |
| 在途 | 成功 | 存原回答，再校验，两臂同一代码 |
| 在途 | 本地语义/引用/结构失败 | 保存失败，不重试；剩余固定样本继续 |
| 在途 | 网络/未知用量/用户停止 | 关闭准入，保留预留和已完成样本；记录终止状态 |
| 任意 | 并发改文件、来源改版、下次启动 | 哈希/目录保护拒绝；不得借重启替换样本 |
| 完成 | 发现质量问题 | 按冻结标准判读，不改 gold、不追加同轮修复 |

## 值 × 读者；新路径 × 检查

| 值 | 唯一写者与读者 | 必须检查 |
|---|---|---|
| 冻结源文/标准/请求/代码 | 准备器 → 本地检查、发送器、评审 | 字节哈希，两个请求除 system 相同 |
| 原始回答与用量 | 单次发送器 → 同一 materialize、评审 | 保留截断/拒答，合法 JSON 与完整引用 |
| 费用记录 | 旧 GuardedTransport → 准入、汇总 | 四个旧 journal 不重算释放；新 cap 不上调 |
| 人工判读 | 助手逐条阅读 → 计数、页面 | 实际 ID 存在，222 机会完整，未评不算 pass |

D346 的标准确认条件已由当前消息满足；D62 的不投票、D345 的独立研究入口、D346 的不把结构检查当语义验收继续适用。模型不读 gold。不同来源/范围、之后的日期和配置变更均需新运行身份；本轮数据写入仅在新目录。
