# 抽取约定的小范围验证

2026-10-27。Alex 要看实际效果，并授权小范围比较。只在研究目录实现；生产抽取、匹配、评判、库和默认模型都不改。

例子：CoreWeave 的 1040 亿美元积压订单应按原主体保留，并成为 NVIDIA 需求的依据；不能写成 NVIDIA 已确认收入。重复调用只测稳定性，不投票，不合并答案。

## 已有证据与本次问题

沿用 [D338 的完整普查和失败结果](../2026-10-27-extraction-stability/results.md)。1,553 次历史抽取中，154 条只连向显示但不允许使用的论点，452 条连接为空，130 条原文检查失败中的 45 条仅为标点前空格不同。这些集合重叠。60 次新实验没有证明加改措辞能整体提高稳定性。请求的字段次序和原文噪声也已发现，不能把全部变化归于模型。

这次测一个结构变化：先对固定原文逐段记下陈述，再对每条陈述选择现有论点。第一步不看随运行变化的论点、分组和新论点准入规则。第二步不能改写或悄悄删除第一步的陈述。没有合适论点的陈述明确待处理，不算成功送入论点库。

D62："Extraction variance is fixed in the prompt, not by sampling several times." 本次重复不是生产多采样。D162 的两步试验仍漏陈述、混淆主体，不能据此声称拆两步就成功。D338："The candidate does not provide an overall stability improvement and is not promoted." 本次是 Alex 新授权的独立验证，不追加旧试验。冻结模块不改；完整新论点构造、归组、匹配、评判及生产推广均在范围外。

## 固定对照与判定

三篇沿用 CoreWeave、Motley Fool、Rest of World 的原文清理版和 31 条先前标注（18 条核心）。它们都属于开发样本，不是独立测试集。所有标签在新输出之前冻结，标签不送给模型。逐条展示每次结果；不调标签、不看完结果追加实验。

四格：Luna 原流程、Luna 分步、DeepSeek 原流程、DeepSeek 分步。每篇每格三次，共 36 个独立结果；原流程一次，分步两次，共最多 54 次 HTTP 请求。轮换顺序，最多两次并发。单个独立结果失败不补抽。传输错误停止新调用。新的研究预算上限 $1.50，最多 54 次，不改变旧预算。

Luna 使用 gpt-6-luna、low、严格 JSON schema。DeepSeek 使用 deepseek-flash（官方当前映射 DeepSeek-V4.1-Flash-1017），关闭 thinking、temperature=0、beta strict 强制函数输出。原流程的 schema 内容不变，只适配官方支持的传输格式。这比较可部署配置，不把参数/协议差异假称为纯模型因果效应。模型名、请求原字节、返回型号、usage、结束原因、用时全部保存。估价使用 Luna 现有配置价格，DeepSeek 峰时价格上界；实际账单不在本地可见。

第一步给完整清理后文章，以程序切出的段和句子编号展示。标题/署名也保留。每段有必填输出项，列陈述或给出空的原因。每条陈述包括起止句号、原主体的一句话、说话者、原发言主体、可确定的原发言日期、层级、事件时间。起止句号只能来自本段且必须正序，程序从原文位置复制连续引文。禁止靠模型重抄引文。逐段回答只证明段落被处理，不证明语义无遗漏。

第二步只显示允许连接的现有论点和每条完整陈述（含程序复制原文），不显示隐藏的组成员。每条陈述必填一个主去向（现有论点、pending、unrelated）及理由；不生成新论点、不改陈述。pending/unrelated 保留在研究记录，均不算现有论点交付成功。POC 仅用一个主去向，不验证多论点传播能力。

同时把已连接记录交给冻结旧版 sift_with_groups，测真正的兼容交付。旧检查按相同引文合并时只留第一条摘要：本次不改它，合并丢失的意思在交付指标中算失败，并单列来源保留/连接后/旧检查后三层。不能用第一步的好结果冒充全流程好结果。

主指标是每条核心陈述三次都保留原意且正确连接的数量，以及最差一次的核心覆盖。原文锚点仅帮助找记录；摘要必须表达被记分的意思，保留主体、数字、单位、时间、计划/实绩/条件和归属，不能靠一大段引文涵盖所有标签得分。原标签中的 required_primary_link 用于连接计分，allowed_links 辅助检查；标签为助手标注，不是独立人类 gold。比较正确性和稳定性，稳定地漏掉也失败。固定开发标签无总体通过率承诺。

记录第一步每段空原因、未命中标签、未连接、错连接、旧检查丢弃、额外陈述；逐条阅读命中核心的不同摘要和未标注陈述，记录语义问题。同一引文重复不增加分数。输出字符量、输入输出 token、估计费用、单结果耗时均按格报告。提示词缩短，schema 的逐段必填会增加输入；此增长专用于可检查覆盖，单列统计，不声称一定省钱。

## 状态 × 事件

| 状态 | 事件 | 动作及记录 |
|---|---|---|
| 未准备 | 原文/标签/映射缺失 | 网络前拒绝 |
| 准备 | 离线检查、审查、preflight 完成 | 冻结字节哈希和调度；时间取原文元数据 |
| 就绪 | 文件变化或重复启动 | 拒绝；不覆盖记录 |
| 第一步在途 | 完整有效回答 | 保存原回答、usage、陈述，再构造第二步 |
| 第一步在途 | schema/引用范围错误、截断 | 保存失败，不发第二步，不补抽 |
| 第二步在途 | 有效回答 | 每条记录去向；旧检查另存结果，源陈述不变 |
| 第二步在途 | 漏项/错值/截断 | 保存失败，第一步仍在；不补抽 |
| 任一步 | 网络失败、崩溃、用户停止 | 不再准入；未知费用保留预算占位，保存已完成/在途结果 |
| 完成 | 分析或另一天启动 | 分析只读；另一次实验必须新目录、新决策，不追加替代样本 |
| 任一步 | 外部生产库变化/其他写者 | 不读取生产新状态；冻结快照隔离，只写本研究目录 |

## 值 × 来源/写者 × 读者

| 值 | 来源与写者 | 全部本次读者/限制 |
|---|---|---|
| 原文、论点列表、标签 | 上次冻结输入 | 预处理、请求、评估；标签不进入模型请求 |
| 句段号及字符范围 | 确定性程序 | 第一步 schema/原文复制/检查；不是模型事实身份 |
| 来源陈述 | 单次第一步 | 第二步、研究存档、评估；不是跨样本身份，不能当作已接纳证据 |
| 去向 | 单次第二步 | 兼容转换器/评估；枚举与显示列表一致 |
| 旧格式证据 | 转换器 | 冻结 sift、评估；不写生产库 |
| 请求、响应、用量 | 研究发送器、供应商 | 审计、费用、评估；原始请求字节发送及保存一致 |
| 日期 | 冻结文章及原文明示内容 | 所有事实判断；墙钟仅计时、非身份/顺序 |

## 新路径 × 原检查

| 路径 | 验证 |
|---|---|
| 两家原流程 | schema 相同、字段顺序固定；原有 quote/link/candidate/group 检查全部执行 |
| 源编号 | 原文逐字覆盖；错误号、逆序、漏段、空原因及非空陈述矛盾均拒绝 |
| 连接 | schema 每陈述必填；显示集合=枚举=接受集合；错号、漏项 mutant 必须失败 |
| 旧检查兼容 | 真实记录作正例；原文/连接故障和合并摘要损失显式计数 |
| 语义计分 | 原标签、原文、实际摘要一起审读；原文命中不等同保留原意 |

| preflight | 付费前冻结旧脚本对已存档记录和临时数据库副本重放；已有拒绝沿用 D338 诊断，不宣称消失 |
